# 速查表：决策规则与关键数字

## 三类专利对比

| 维度 | 发明 | 实用新型 | 外观设计 |
|---|---|---|---|
| 客体（第2条） | 产品、方法或其改进的新技术方案 | 产品形状、构造或其结合的适于实用的新技术方案 | 产品整体或局部的形状/图案/色彩组合，富有美感、适于工业应用 |
| 授权条件 | 新颖性 + 创造性（突出的实质性特点 + 显著的进步）+ 实用性（第22条） | 新颖性 + 创造性（实质性特点 + 进步）+ 实用性（第22条） | 非现有设计、无抵触申请、明显区别、不冲突在先权利（第23条） |
| 审查 | 初步审查 + 实质审查（第34–39条） | 仅初步审查（第40条） | 仅初步审查（第40条） |
| 保护期（自申请日） | 20年 | 10年 | 15年（第42条） |
| 排他行为（第11条） | 制造、使用、许诺销售、销售、进口；方法及其直接获得的产品 | 同发明 | 制造、许诺销售、销售、进口（无"使用"） |

| 开放许可声明 | 直接声明 | 须附评价报告 | 须附评价报告（第50条） |

## 决策规则

- 申请类型：有"方法"→ 发明；只有形状/构造且要快 → 实用新型；两者都想要 → 同日双申请，发明授权时放弃实用新型（第9条）。
- 归属：执行单位任务 或 主要用单位资源 → 单位；否则 → 个人；仅用资源且有约定 → 从约定（第6条）。
- 公开在申请前：属第24条四种情形且≤6个月 → 仍可申请；否则 → 新颖性已失。
- 向外国申请：在中国完成 → 先保密审查，否则中国不授权（第19条）。
- 转让：签书面合同 + 登记公告 → 登记之日生效（第10条）。
- 共有：无约定 → 只能单独实施或给普通许可；独占/排他/转让 → 全体同意（第14条）。
- 审查意见：任何"指定期限"→ 默认后果是视为撤回，不是延期（第35–37条）。
- 驳回：3个月复审 → 3个月起诉，不能跳级（第41条）。
- 维权：要快停 → 行政处理；要赔偿 → 法院；怕证据灭失/损害不可弥补 → 诉前保全（第65、72、73条）。
- 赔偿举证：损失/获利 → 许可费倍数 → 法定赔偿；对方藏账簿 → 请求责令提供并按己方主张判（第71条）。
- 被告防御顺序：不落入权利要求 → 现有技术 → 第75条五种例外 → 合法来源（只免赔）→ 时效 → 同时提无效（第64、67、75、77、74、45条）。

## 侵权判断决策树

1. 行为是否在第11条动词清单内且为生产经营目的？否 → 不侵权。
2. 技术方案/外观是否落入权利要求（或图片照片）范围？（第64条）否 → 不侵权。
3. 是否属于现有技术/现有设计？（第67条）是 → 不侵权。
4. 是否属于第75条五种情形（权利用尽、先用权、临时过境、科研实验、行政审批）？是 → 不视为侵权。
5. 是否合法来源的不知情销售/使用者？（第77条）是 → 停止但不赔偿。
6. 是否超过3年时效？（第74条）是 → 抗辩时效。
7. 否则 → 侵权成立，进入第71条赔偿阶梯。

## 失权信号（看到就要警惕）

- 申请日快满3年还没请求实审。
- 审查意见"指定期限"临近而无人处理。
- 年费缴纳期临近。
- 产品发布/论文发表排在申请之前。
- 优先权声明有了但副本未交（16个月/3个月）。
- 在中国研发完成、准备直接去外国申请。
- 实用新型准备维权或声明开放许可但没有专利权评价报告。
- 知道侵权已近3年仍未起诉。

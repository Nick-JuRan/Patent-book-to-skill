## 核心规则与思维模型

**客体与归属（第一章）**
- 三类发明创造：发明（产品/方法/其改进的新技术方案）、实用新型（产品形状/构造的新技术方案）、外观设计（整体或局部的形状/图案/色彩组合，富有美感、适于工业应用）。有"方法"只能走发明；外观设计2020年起含"局部"。（第2条）
- 归属三步：执行单位任务 或 主要利用单位物质技术条件 → 单位；否则 → 发明人/设计人；仅利用单位资源且有合同约定 → 从约定。合作/委托无协议 → 归完成方。（第6、8条）
- 先申请 + 一发明一专利：同样的发明创造只授一项，多人申请给最先申请者；唯一例外是同一申请人同日双申请，发明授权时放弃实用新型。（第9条）
- 排他清单：发明/实用新型禁止未经许可为生产经营目的制造、使用、许诺销售、销售、进口专利产品及使用专利方法/其直接产品；外观设计不含"使用"。（第11条）
- 形式要件：转让须书面合同 + 登记公告，登记之日生效；共有无约定只能单独实施或给普通许可。（第10、14条）
- 两条涉外硬规则：中国完成的发明/实用新型向外国申请前须保密审查，否则中国不授权；在华无居所/营业所的外国主体必须委托专利代理机构。（第18、19条）
- 诚实信用：申请和行权守诚信；滥用专利权构成垄断依反垄断法处理。（第20条）

**授权条件（第二章）**
- 三性以申请日为界、国内外公开一律算现有技术：新颖性（不属现有技术且无抵触申请）、创造性（发明：突出的实质性特点 + 显著的进步；实用新型：实质性特点 + 进步）、实用性（能制造/使用且有积极效果）。（第22条）
- 外观设计三关：非现有设计且无抵触申请、与现有设计或其特征组合有明显区别、不冲突他人在先合法权利。（第23条）
- 宽限期是保险不是策略：申请日前6个月内仅四种公开（紧急状态公共利益首次公开、中国政府主办/承认的国际展览会首次展出、规定的学术/技术会议首次发表、他人未经同意泄露）不丧失新颖性。（第24条）
- 六类不授权客体：科学发现、智力活动规则和方法、疾病诊断和治疗方法、动植物品种（其生产方法可授）、原子核变换方法及所得物质、平面印刷品上主要起标识作用的设计。（第25条）

**申请与审查（第三、四章）**
- 说明书是存款、权利要求是取款：说明书须让所属技术领域的技术人员能实现，权利要求以说明书为依据；修改不得超出原始记载范围。（第26、33条）
- 优先权 12/6 个月（发明、实用新型 / 外观设计）+ 申请时书面声明 + 副本（16个月 / 3个月），缺一视为未要求。（第29、30条）
- 发明时间线：申请日 → 满18个月公布 → 3年内请求实审 → 审查意见指定期限内答复 → 授权公告生效。三处逾期均视为撤回。实用新型/外观设计初步审查即授权。（第34–40条）
- 驳回救济固定两级：3个月复审 → 3个月起诉。（第41条）

**期限、终止、无效（第五章）**
- 20 / 10 / 15 年，全部自申请日起算。（第42条）
- 两类期限补偿都要请求：审批延迟（申请满4年且实审请求满3年后授权，扣申请人自身延迟）；新药（≤5年，上市后总有效期≤14年）。（第42条）
- 不缴年费或书面放弃 → 提前终止。任何人授权公告后可请求无效，不服决定3个月内起诉。（第43–46条）
- 无效自始不存在，但已执行判决、已履行合同不追溯，恶意除外，明显不公应返还。（第47条）

**许可（第六章）**
- 开放许可 = 挂牌定价：书面声明 + 公告费率 → 任何人付费即得；期间年费减免；可加普通许可，不得独占/排他；实用新型/外观设计须附专利权评价报告。（第50–52条）
- 强制许可五事由（仅发明和实用新型）：不实施（授权满3年且申请满4年）、垄断、紧急状态/公共利益、公共健康药品出口、从属专利；三限制：半导体仅限公共利益和反垄断、主要供国内市场、先以合理条件请求许可未果。被许可人不独占、不转授、付合理使用费。（第53–63条）

**保护（第七章）**
- 保护范围以权利要求为准，说明书附图只用于解释。（第64条）
- 双轨维权：行政处理可责令立即停止（不服15日内起诉）；法院管赔偿；诉前可申请行为/财产/证据保全。（第65、72、73条）
- 赔偿阶梯：实际损失或侵权获利 → 许可费倍数 → 法定3万–500万；故意且情节严重 1–5 倍惩罚性赔偿；含合理开支；对方藏账簿可按权利人主张判。（第71条）
- 被告四张牌：现有技术抗辩（第67条）、五种不视为侵权（权利用尽、先用权、临时过境、科研实验、行政审批 Bolar 例外，第75条）、合法来源只免赔偿不免停止（第77条）、3年时效（第74条）。
- 新产品制造方法专利举证倒置；实用新型/外观设计维权备专利权评价报告。（第66条）
- 药品专利链接：上市审评阶段可诉请确认是否落入保护范围，药监可据生效裁判暂停批准。（第76条）

## 范围与限制

本技能只覆盖《专利法》2020年修正文本（82条）本身。不含《专利法实施细则》《专利审查指南》、司法解释和地方规定；涉及"按照规定"的具体标准（费用、期限计算细节、审查基准）需另行查阅。文本中未载明第四次修正决定的施行日期。回答法律问题时应引用条文号，并提示用户以官方发布文本和专业意见为准。

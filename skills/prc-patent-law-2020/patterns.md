# 操作模式（法定程序与策略）

## 选择专利类型
**何时用**：有了技术方案或产品外观，决定申请路线。
**怎么做**：涉及方法 → 发明；只改产品形状/构造且想快速授权 → 实用新型（无实审，10年）；卖点是外观（含局部）→ 外观设计（15年）。方案同时满足发明与实用新型条件 → 见下一模式。（第2、22、23、40、42条）
**取舍**：发明保护期长、稳定但审批慢；实用新型快但创造性门槛低、稳定性弱，维权常需专利权评价报告。

## 同日双申请
**何时用**：希望尽早获得保护，又想拿到20年发明专利。
**怎么做**：同一申请人同日对同样的发明创造既申请实用新型又申请发明；实用新型先授权；发明授权时，若实用新型尚未终止且申请人声明放弃实用新型 → 授予发明专利权。（第9条第1款）
**取舍**：只能保留一项；需在申请时同日提交，不能事后补。

## 主张优先权
**何时用**：已在外国或中国有首次申请，想把申请日前移。
**怎么做**：发明/实用新型在首次申请日起12个月内、外观设计6个月内就相同主题申请；申请时书面声明；发明/实用新型在首次申请日起16个月内交首次申请文件副本，外观设计在3个月内交副本。（第29、30条）
**取舍**：逾期或未声明视为未要求；只覆盖"相同主题"。

## 利用新颖性宽限期
**何时用**：申请前已发生公开，评估是否还能申请。
**怎么做**：核对公开是否属于第24条四种情形（紧急状态公共利益首次公开；中国政府主办/承认的国际展览会首次展出；规定的学术/技术会议首次发表；他人未经同意泄露），且距申请日不超过六个月。
**取舍**：只是不算现有技术，不产生在先日期；其他任何公开（官网、电商、论文预印本）都不在内。

## 推进发明审批
**何时用**：发明申请提交后。
**怎么做**：需要尽早公布（触发临时保护）→ 请求早日公布；在申请日起3年内请求实审并提交参考资料；外国审查结果按要求期限提交；每份审查意见在指定期限内陈述意见或修改（修改不超原始记载范围）；驳回 → 3个月内复审 → 3个月内起诉。（第13、33–41条）
**取舍**：三处逾期都视为撤回，无自动延期。

## 请求专利权期限补偿
**何时用**：发明授权时距申请日已满4年且距实审请求已满3年；或新药专利获上市许可。
**怎么做**：由专利权人向国务院专利行政部门提出请求；审批延迟补偿扣除申请人自身造成的延迟；新药补偿不超过5年且上市后总有效期不超过14年。（第42条第2、3款）
**取舍**：必须主动请求；申请人拖延不补。

## 开放许可（权利人侧 / 实施人侧）
**何时用**：权利人想低成本广泛授权并减免年费；实施人想快速合法取得许可。
**怎么做**：权利人书面声明 + 明确费率与支付方式（实用新型/外观设计附评价报告）→ 公告；实施人书面通知权利人并按公告标准付费 → 即得许可；权利人可另给普通许可，不得给独占/排他许可；撤回须书面并公告，不影响在先许可；纠纷协商 → 部门调解或起诉。（第50–52条）
**取舍**：权利人失去排他授权的灵活性，换年费减免和交易效率。

## 申请强制许可
**何时用**：权利人不实施/未充分实施、垄断行为、紧急状态/公共利益、公共健康药品出口、从属专利受阻。
**怎么做**：确认事由与门槛（不实施型：授权满3年且申请满4年、无正当理由）；不实施型和从属型先以合理条件请求许可并保留证据；向国务院专利行政部门申请；获准后不独占、不转授、付合理使用费（协商不成由部门裁决）；不服决定或裁决3个月内起诉。（第53–63条）
**取舍**：只适用于发明和实用新型；半导体仅限公共利益和反垄断事由；主要供应国内市场。

## 选择维权路径
**何时用**：发现侵权。
**怎么做**：先固定证据（必要时诉前证据保全）；需要快速停止 → 请求管理专利工作的部门处理（可责令立即停止；对方15日内不起诉又不停止可申请强制执行）；需要赔偿 → 向法院起诉（或先在行政程序中调解赔偿）；即将受难以弥补损害 → 诉前行为保全/财产保全；全国重大影响案件可请国务院专利行政部门处理，跨区域案件可请上级部门合并处理。（第65、70、72、73条）
**取舍**：行政快但不判赔偿；司法全面但周期长；两者可并行。

## 主张与证明赔偿
**何时用**：起诉索赔。
**怎么做**：按阶梯举证——实际损失或侵权获利 → 许可费倍数 → 法定赔偿（3万–500万）；有故意且情节严重证据（警告函后继续、扩大规模等）→ 主张1–5倍惩罚性赔偿；账簿在对方手中 → 申请法院责令提供，对方不提供则请求参考己方主张判定；一并主张合理开支。新产品制造方法专利 → 要求对方证明其方法不同。实用新型/外观设计 → 备好专利权评价报告。（第66、71条）
**取舍**：法定赔偿最省举证但金额受限；惩罚性赔偿依赖对"故意 + 情节严重"的证明。

## 侵权抗辩组合（被告侧）
**何时用**：被诉侵权。
**怎么做**：依次检查——技术方案是否落入权利要求（第64条）；是否现有技术/现有设计（第67条）；是否权利用尽、先用权、临时过境、科研实验、行政审批 Bolar 例外（第75条）；是否合法来源（第77条，仅免赔偿）；是否已过3年诉讼时效（第74条）；同时向国务院专利行政部门请求宣告无效（第45条）。
**取舍**：无效成功则自始不存在，但已执行判决不追溯（第47条）；合法来源不免除停止销售。

## 药品上市阶段的专利争议
**何时用**：仿制药申请上市，或原研专利权人发现仿制申请。
**怎么做**：任一方可向法院起诉请求确认注册药品技术方案是否落入专利保护范围，或向国务院专利行政部门请求行政裁决；药监部门可依生效裁判决定是否暂停批准。（第76条）
**取舍**：提前解决争议避免上市后侵权，但具体衔接办法在本法之外。

## 涉外申请合规
**何时用**：外国主体来华申请，或中国完成的发明要出境申请。
**怎么做**：外国主体（在中国无经常居所/营业所）必须委托依法设立的专利代理机构；中国完成的发明/实用新型向外国或提出国际申请前先报保密审查；向外国人转让申请权/专利权依法办手续。（第10、18、19条）
**取舍**：跳过保密审查的后果是中国不授权并可能追责。

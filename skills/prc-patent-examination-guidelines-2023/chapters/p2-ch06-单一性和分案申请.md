# 第二部分 第六章 单一性和分案申请

## 核心要点
判断一件申请中两项以上发明是否"属于一个总的发明构思"只有一个标准：权利要求之间是否包含相同或者相应的**特定技术特征**（对现有技术作出贡献的技术特征）；不满足时要求修改，申请人可自愿分案，分案内容不得超出原申请记载的范围。

## 审查标准与框架

- **单一性要求**（§2.1.1，法31.1）：一件申请应当限于一项发明或实用新型；属于一个总的发明构思的两项以上发明或实用新型可以作为一件申请提出。理由：经济上防止只付一件费用获得几项保护；技术上便于分类、检索和审查。缺乏单一性不影响专利的有效性，不应当作为无效理由。

- **总的发明构思 = 相同或者相应的特定技术特征**（§2.1.2，细则39）：两项以上发明应当在技术上相互关联，包含一个或多个相同或者相应的特定技术特征。特定技术特征指每一项发明作为整体对现有技术作出贡献的技术特征，即使发明相对于现有技术具有新颖性和创造性的技术特征；应从每一项要求保护的发明的整体上考虑后确定。

- **审查六原则**（§2.2.1，法31.1，细则39）：
  1. 看权利要求记载的技术方案的实质性内容是否包含使其技术上相互关联的相同或相应的特定技术特征；依权利要求内容判断，必要时参照说明书和附图。
  2. 六种允许的撰写方式：（i）不能包括在一项权利要求内的两项以上产品或方法的同类独立权利要求；（ii）产品 + 专用于制造该产品的方法；（iii）产品 + 该产品的用途；（iv）产品 + 专用制造方法 + 用途；（v）产品 + 专用制造方法 + 为实施该方法而专门设计的设备；（vi）方法 + 专门设计的设备。不属于一个总的发明构思的，即使按此撰写也不允许。"专用"方法的使用结果就是获得该产品，但不意味产品不能用其他方法制造；用途必须由产品的特定性能决定；"专门设计"的设备除能实施该方法外，其对现有技术的贡献还必须与方法的贡献相对应，但不意味设备不能实施其他方法。是否按引用关系撰写只是形式差异，不影响单一性。
  3. 六种方式并非穷举。
  4. 分别在各自独立权利要求中保护，还是在同一权利要求中作为并列选择方案保护（马库什权利要求，第十章§8.1），按相同标准判断；排列次序不影响判断。
  5. 一般只考虑独立权利要求之间的单一性，从属权利要求与其所从属的独立权利要求之间不存在缺乏单一性问题；形式从属、实质独立的应当审查；独立权利要求因缺乏新颖性、创造性不能授权时，需考虑其从属权利要求之间的单一性。
  6. 明显不具有一个总的发明构思的（除草剂 + 割草机）检索前即可判定；特定技术特征相对于现有技术而言，多数申请须检索后判断；第一独立权利要求的新颖性或创造性被否定后，其余并列独立权利要求之间是否仍属一个总的发明构思应当重新确定。

- **审查方法**（§2.2.2）：检索前先判明显缺乏单一性——各项发明没有相同或相应的技术特征，或共有的相同/相应技术特征均属于本领域惯用的技术手段 → 明显不具有单一性。否则三步法：（1）第一项发明与相关现有技术比较，确定其特定技术特征；（2）判断第二项发明中是否存在相同或者相应的特定技术特征；（3）存在 → 属于一个总的发明构思；不存在 → 不具有单一性。

- **同类独立权利要求判定规则**（§2.2.2.1）：各有不相关特定技术特征A、B的两项无单一性，同时含A和B的第三项与二者各有单一性（例1传送带）；必须配合使用、彼此相应的特定技术特征（发射器时轴扩展器与接收器时轴压缩器；插头与相应插座）→ 有单一性（例2、3）；制造同一新产品A的方法B、C、D以A为相同特定技术特征有单一性，A已知则须重新判断（例6）；共有特征已知且组合无贡献（树脂A + 填料B），特定技术特征分别为ABC、ABD组合 → 无单一性（例7）。

- **不同类独立权利要求判定规则**（§2.2.2.2）：产品的特定技术特征是性能参数（屈服强度），方法的工艺步骤正是为获得该性能而采用——措词未体现但说明书清楚可见 → 相应的特定技术特征，有单一性（例9不锈钢带）；聚焦同一贡献点（正切方向燃料进料口）的燃烧器、制法、设备、使用方法有单一性，以浇铸工序、自动控制装置D为特征者与之均无、彼此亦无（例13）。

- **从属权利要求的单一性**（§2.2.2.3）：合规从属权利要求即使包含另外的发明（新温度范围；原料B由C制备；叶片由新合金A制造且应用有创造性）也不存在缺乏单一性问题。形式从属、实质独立（以特征D代替C，未包含在前权利要求的全部特征）→ 按同类独立权利要求规则审查。独立权利要求被否定后，剩下的从属权利要求视为独立权利要求判断。

- **分案的三种情形**（§3.1，细则48）：（1）原权利要求书包含不属于一个总的发明构思的两项以上发明 → 要求限制至其中一项（一般是权利要求1对应的发明）或属于一个总的发明构思的两项以上发明；（2）修改时将原仅在说明书中描述的发明作为独立权利要求增加或替换，且与原权利要求书中的发明缺乏单一性 → 一般应当要求删除；（3）独立权利要求之一（通常权利要求1）缺乏新颖性或创造性，导致其余并列独立权利要求之间甚至从属权利要求之间失去相同或相应的特定技术特征 → 需要修改。删除的发明均可分案。分案是申请人自愿的行为，审查员只需要求改为一项或属于一个总的发明构思的几项发明，是否分案由申请人决定。可提一件或多件分案；对分案申请可以原申请为依据再分案，但递交日不符合第一部分第一章§5.1.1(3)的不能允许，除非审查员指出了单一性缺陷。

- **分案申请的要求**（§3.2，细则49.1，法33，细则59(3)）：（1）说明书起始部分（所属技术领域之前）写明是哪件申请的分案及原申请的申请日、申请号、发明创造名称；（2）内容不得超出原申请记载的范围，否则以不符合细则49.1或法33驳回；（3）分案后原申请与分案申请的权利要求书分别保护不同的发明，说明书可相同（A和B）或各自只保留（A / B）。申请人、递交时间、类别适用第一部分第一章§5.1.1。

- **分案的审查**（§3.3，细则48、49、59(3)）：分案内容超范围 → 要求修改，不修改或仍超范围 → 依细则59(3)以不符合细则49.1或法33驳回；不符合法31.1和细则39 → 依细则48.2通知在指定期限内修改，并提醒：无正当理由期满未答复视为撤回，无充分理由不改为具有单一性的申请可依法31.1驳回；分案申请不符合单一性同样处理；其余审查与一般申请相同。

## 关键概念
- **单一性**：一件申请限于一项发明或实用新型，或属于一个总的发明构思的两项以上（§2.1.1，法31.1）
- **总的发明构思**：两项以上发明技术上相互关联，包含相同或者相应的特定技术特征（§2.1.2，细则39）
- **特定技术特征**：每一项发明作为整体对现有技术作出贡献、使其具有新颖性和创造性的技术特征（§2.1.2）
- **相应的特定技术特征**：不相同但彼此对应、相互关联的特定技术特征，如必须配合使用的插头与插座、为获得产品性能而采用的工艺步骤（§2.2.2.1–2）
- **同类独立权利要求**：仅涉及产品发明或仅涉及方法发明的多项独立权利要求（§2.2.1(2)）
- **专用于制造该产品的方法 / 专门设计的设备**：使用结果即得该产品的方法；能实施该方法且贡献与方法贡献相对应的设备（§2.2.1(2)）
- **形式从属实质独立的权利要求**：引用在前权利要求但未包含其全部特征者，按独立权利要求审单一性（§2.2.2.3）
- **明显缺乏单一性**：无共有技术特征，或共有特征均为惯用技术手段，检索前即可判定（§2.2.2）

## 思维模型
- 把单一性还原为一问："这几项权利要求共有的、对现有技术作出贡献的特征是什么？"共有特征若已知或惯用，就不是特定技术特征，共有再多也无单一性。
- 特定技术特征是相对量：随现有技术而变；检索结果一出（尤其权利要求1被否定），重新做单一性判断。
- 单一性不传递：A与B有、B与C有，不代表A与C有；每一对独立权利要求分别核对（例10涂料—方法—设备）。
- 分案是申请人的权利而非审查员的处分：审查员只要求"改到符合单一性"，分不分由申请人定；边界始终是原申请记载的范围。

## 反模式
- **按六种撰写方式套格式即认定有单一性**：格式合规不等于属于一个总的发明构思（§2.2.1(2)）。
- **以共有的已知特征或惯用手段认定单一性**：ABC与ABD仅共有已知的AB，无单一性（例7）。
- **权利要求1被否定后沿用原单一性结论**：产品已知时其制法与用途之间失去特定技术特征，须重新确定（例8，§2.2.1(6)）。
- **对合规从属权利要求提单一性意见**：即使其包含可独立成立的发明（新合金A）也不得提（§2.2.2.3）。
- **把替换特征的"从属"权利要求当从属处理**：以D替换C者实为独立权利要求，须审单一性（§2.2.2.3）。
- **以缺乏单一性主张无效**：不是无效理由（§2.1.1）。
- **审查员强令分案**：只能要求限制至符合单一性的发明（§3.1）。
- **分案申请加入原申请未记载的内容**：依细则59(3)以细则49.1或法33驳回（§3.3(1)）。

## 实例演练
**例A：化合物X三件套**（例8，§2.2.2.2）——权利要求1化合物X，2制备X的方法，3 X作为杀虫剂的应用。共有特征X。检索后X新且有创造性 → X是相同的特定技术特征 → 1、2、3有单一性（方式(iv)）。若X已被公开 → 1不授权；2与3之间X不再作贡献，制备工艺与杀虫用途亦无相应的特定技术特征 → 2与3缺乏单一性，要求限制至其一，另一项可分案（§3.1(3)）。

**例B：显示器从属权利要求的转性**（§2.2.2.3）——1显示器（A + B），2 = 1 + C，3 = 1 + D。情形一：A + B新且有创造性 → 2、3是进一步限定的从属权利要求，三项有单一性。情形二：两份对比文件结合使1无创造性，C、D各自体现贡献且完全不相关 → 2、3视为独立权利要求；C与D不相同也不相应 → 2与3无单一性。

## 关键要点
1. 唯一标准：权利要求之间存在相同或者相应的特定技术特征——每项发明整体上对现有技术作出贡献的技术特征。
2. 先筛"明显缺乏单一性"（无共有特征或共有特征均为惯用手段），再三步法（定第一项特定技术特征 → 找第二项是否有相同/相应者 → 结论）。
3. 六种撰写方式是许可形式而非充分条件，也非穷举；引用关系、排列次序不影响单一性。
4. 从属权利要求不审单一性，但形式从属实质独立者及独立权利要求被否定后剩下的从属权利要求按独立权利要求审；检索否定权利要求1后须重新确定其余各项的单一性。
5. 缺乏单一性 → 通知在指定期限内修改；不答复视为撤回，无充分理由不改可依法31.1驳回；分案自愿，不得超出原申请记载范围。

# 第二部分 第一章 不授予专利权的申请

## 核心要点
新颖性、创造性之前先审客体：主题是否属于法2.2的技术方案，是否落入法5或法25的排除；落入者不论是否新颖、有创造性，一律不授权。

## 审查标准与框架

- **技术方案判断**（§2，法2.2）：发明是"对产品、方法或者其改进所提出的新的技术方案"；技术方案是对要解决的技术问题所采取的利用了自然规律的技术手段的集合。未采用技术手段解决技术问题、以获得符合自然规律的技术效果的方案 → 不属于客体。气味及声、光、电、磁、波等信号或能量本身不是客体，利用其性质解决技术问题的不属此列。法2.2是一般性定义，不是新颖性、创造性的审查标准。

- **违反法律的发明创造**（§3.1.1，法5.1，细则10）："法律"仅指全国人大或其常委会依照立法程序制定和颁布的法律，不包括行政法规和规章。本身违法（赌博设备、吸毒器具、伪造货币、票据、公文、证件、印章的设备）→ 不授权。不排除：本身不违法、因滥用才违法的（医用毒药、麻醉品、娱乐棋牌）；细则10"仅其实施为法律所禁止"的——仅产品的生产、销售或使用受法律限制，产品本身及其制造方法仍可保护（武器）。

- **违反社会公德的发明创造**（§3.1.2，法5.1）：社会公德指公众普遍认为是正当的、并被接受的伦理道德观念和行为准则，限于中国境内。排除：暴力凶杀或淫秽内容；非医疗目的的人造性器官；人与动物交配的方法；改变人生殖系遗传同一性的方法或改变了生殖系遗传同一性的人；克隆的人或克隆人的方法；人胚胎的工业或商业目的的应用；可能导致动物痛苦而对医疗没有实质性益处的改变动物遗传同一性的方法。例外：利用未经过体内发育的受精14天以内的人类胚胎分离或获取干细胞的，不能以此拒绝。

- **妨害公共利益的发明创造**（§3.1.3，法5.1）：实施或使用会给公众或社会造成危害，或使国家和社会的正常秩序受到影响。排除：以致人伤残或损害财物为手段（使盗窃者失明的防盗装置）；严重污染环境、严重浪费能源或资源、破坏生态平衡、危害公众健康；涉及政党象征和标志、国家重大政治事件、伤害人民感情或民族感情、宣扬封建迷信，或涉及国家重大经济、文化事件、宗教信仰以致妨害公共利益。例外：因滥用而可能妨害公共利益的，或产生积极效果的同时存在某种缺点的（有副作用的药品），不能以此拒绝。

- **部分违反法5.1的申请**（§3.1.4）：含违法内容而其他部分合法 → 通知申请人删除违法部分；不同意删除 → 不授权，即使是新的、有创造性的技术方案。

- **依赖违规遗传资源完成的发明创造**（§3.2，法5.2，细则29.1）：两要件同时满足才排除：（1）获取或利用遗传资源违反法律、行政法规的禁止性规定，或未事先获得有关行政管理部门的批准或相关权利人的许可；（2）发明创造利用了遗传资源的遗传功能——对遗传功能单位进行分离、分析、处理或对其遗传信息进行分析和利用。此处依据含行政法规，与§3.1.1不同。

- **科学发现**（§4.1，法25.1(1)）：对自然界中客观存在的物质、现象、变化过程及其特性和规律的揭示（含科学理论）→ 不授权；利用该发现的技术方案可授权（卤化银感光特性 vs 感光胶片及其制造方法）。找到天然形态存在的未知物质仅是发现；首次从自然界分离或提取的物质适用第十章§2.1。

- **智力活动的规则和方法两原则**（§4.2，法25.1(2)，法2.2）：智力活动是人的思维运动，其规则和方法未采用技术手段或利用自然规律、未解决技术问题和产生技术效果，既不符合法2.2又属法25.1(2)。
  - 原则（1）：权利要求仅仅涉及智力活动的规则和方法 → 不授权；除其主题名称以外，对其进行限定的全部内容均为智力活动的规则和方法 → 实质上仅仅涉及，同样不授权（管理方法及制度、比赛规则、汉字编码方法、数学理论、游戏规则、信息表述方法、计算机程序本身等）。
  - 原则（2）：限定内容既包含智力活动的规则和方法，又包含技术特征 → 就整体而言不是智力活动的规则和方法，不应当依据法25排除（含技术特征的商业模式权利要求），转法2.2审查。

- **疾病的诊断和治疗方法**（§4.3，法25.1(3)）：以有生命的人体或者动物体为直接实施对象，进行识别、确定或消除病因或病灶的过程。排除理由：医生应有选择方法和条件的自由；以活体为对象无法在产业上利用。诊疗用仪器、装置、物质、材料可授权。

- **诊断方法两条件**（§4.3.1.1）：同时满足即属诊断方法：（1）以有生命的人体或动物体为对象；（2）以获得疾病诊断结果或健康状况为直接目的。表述上以离体样品为对象，但以获得同一主体疾病诊断结果或健康状况为直接目的 → 仍排除。包括诊断步骤，或仅包括检测步骤但根据现有技术中的医学知识和申请公开的内容，知晓该信息即能直接获得诊断结果或健康状况 → 满足条件（2）（诊脉法、X光诊断法、患病风险度评估方法、基因筛查诊断法）。
  - 不属于（§4.3.1.2）：对已死亡人体或动物体的病理解剖方法；只是从活体或离体组织、体液、排泄物获取或处理"中间结果"信息的方法（中间结果：从信息本身不能直接得出诊断结果或健康状况的信息）；全部步骤由计算机等装置实施的信息处理方法。

- **治疗方法**（§4.3.2）：为使有生命的人体或动物体恢复或获得健康或减少痛苦，进行阻断、缓解或消除病因或病灶的过程；包括以治疗为目的或具有治疗性质的各种方法；预防疾病或者免疫的方法视为治疗方法。既可能包含治疗目的又可能包含非治疗目的的方法 → 应当明确说明用于非治疗目的，否则不授权。
  - 属于或视为（§4.3.2.1）：外科手术治疗、药物治疗、心理疗法；治疗目的的针灸、麻醉、推拿、药浴、护理、辐射照射、涂覆、冷冻、透热；免疫方法；手术或药物治疗的辅助方法（返回同一主体的细胞、组织或器官的处理、血液透析、麻醉深度监控、给药）；治疗目的的受孕、避孕、体外受精、胚胎转移、整容、减肥、增高；处置伤口；人工呼吸、输氧。药物本身可授权，医药用途适用第十章§2.2、§4.5.2。
  - 不属于（§4.3.2.2）：制造假肢或假体的方法及为此实施的测量方法；非外科手术方式处置动物体以改变其生长特性的畜牧业生产方法；动物屠宰；对已死亡人体或动物体的处置；单纯的美容方法（不介入人体或不产生创伤，在体表可视部位实施的非治疗目的除臭、保护、装饰或修饰）；为非病态者或潜水、防毒时输送氧气、负氧离子、水分；杀灭体外（不含伤口和感染部位）细菌、病毒、虱子、跳蚤。

- **外科手术方法**（§4.3.2.3）：使用器械对活体实施的剖开、切除、缝合、纹刺等创伤性或介入性治疗或处置的方法。治疗目的 → 依法25.1(3)排除；非治疗目的 → 适用第五章§3.2.4（实用性）；对已死亡人体或动物体实施的，不违反法5.1即可授权。

- **动物和植物品种**（§4.4，法25.1(4)、25.2）：动物指只能靠摄取自然的碳水化合物及蛋白质维系生命的生物（不包括人）；植物指借助光合作用以无机物合成有机物维系生存、通常不移动的生物。品种本身不授权（植物新品种走《植物新品种保护条例》）。生产方法可授权，但限于非生物学的方法：人的技术介入对方法所要达到的目的或效果起了主要的控制作用或者决定性作用 → 不属于"主要是生物学的方法"（辐照饲养法生产高产乳牛）。微生物及微生物方法可授权，适用第十章。

- **原子核变换方法及所获物质**（§4.5，法25.1(5)）：使原子核经分裂或聚合形成新原子核的过程（磁镜阱法、封闭阱法、核裂变方法）及用该方法获得的物质（放射性同位素）→ 不授权。可授权：为实现核变换而增加粒子能量的粒子加速方法、核变换设备、仪器及零部件、同位素的用途及所用仪器设备。

- **真实发明创造活动审查**（§5，法20.1，细则11）：适用《规范申请专利行为的规定》。

## 关键概念
- **技术方案**：对要解决的技术问题所采取的利用了自然规律的技术手段的集合（§2）
- **社会公德**：公众普遍认为是正当的、并被接受的伦理道德观念和行为准则，限于中国境内（§3.1.2）
- **遗传资源**：含有遗传功能单位并具有实际或潜在价值的材料及其产生的遗传信息（§3.2）
- **科学发现**：对自然界中客观存在的物质、现象、变化过程及其特性和规律的揭示（§4.1）
- **智力活动的规则和方法**：指导人们进行思维、表述、判断和记忆的规则和方法（§4.2）
- **诊断方法**：为识别、研究和确定活体病因或病灶状态的过程（§4.3.1）
- **中间结果**：从信息本身不能直接得出疾病诊断结果或健康状况的信息（§4.3.1.2）
- **治疗方法**：为使活体恢复或获得健康或减少痛苦，进行阻断、缓解或消除病因或病灶的过程（§4.3.2）
- **主要是生物学的方法**：人的技术介入未对目的或效果起主要控制或决定性作用的动植物生产方法（§4.4）

## 思维模型
- 两道闸门：先问"是否利用自然规律解决技术问题的技术方案"（法2.2），再问"是否落入法5、法25的明示排除"；都过了才谈新颖性、创造性。
- 作用于人体或动物体的方法，锁定"直接对象"与"直接目的"：活体 + 诊断结果或治疗效果 → 排除；死体、离体样品仅得中间结果、目的为制造/生产/美容 → 不排除。
- 区分"发明创造本身"与"其实施或滥用"：本身违法、违背公德、损害公益才排除；仅实施受限、被滥用才有害、积极效果伴随缺点 → 不排除。法25排除的是方法、发现、品种本身，配套仪器、物质、药物、设备、用途均可授权。

## 反模式
- **以行政法规或规章认定"违反法律"**：法5.1的"法律"仅指全国人大及其常委会制定的法律（§3.1.1）；法5.2遗传资源违规才可依据行政法规（§3.2）。
- **因产品的生产、销售、使用受法律限制就拒绝授权**：细则10排除"仅其实施为法律所禁止"的情形（§3.1.1）。
- **以药品有副作用认定"妨害公共利益"**（§3.1.3）；**对部分违法申请直接整体驳回**，应先通知删除（§3.1.4）。
- **给智力活动规则套上"系统/装置"主题名称**：主题名称外全部限定内容均为规则的仍依法25.1(2)排除；反之，含技术特征的商业方法权利要求不得依法25驳回（§4.2）。
- **把离体样品检测一律视为可授权**：以获得同一主体诊断结果为直接目的的仍是诊断方法（§4.3.1.1）；**双重目的方法不限定为非治疗目的** → 按治疗方法排除（§4.3.2）。
- **把非治疗目的的外科手术方法依法25驳回**：应按第五章§3.2.4实用性审查（§4.3.2.3）。

## 实例演练
**例1：投币式弹子游戏机**（§3.1.4）——达到一定分数时机器抛出钱币。抛币部分构成赌博、违反法律，其余为合法的游戏机结构。审查员通知申请人删除或修改抛币部分，使之成为单纯的投币式游戏机；拒绝 → 即使新颖且有创造性也不授权。

**例2：诊断方法两条件走一遍**（§4.3.1）——"检测离体血样中标志物X浓度的方法"：形式上对象是离体样品，关键看直接目的。若按现有医学知识和申请公开内容，知晓X浓度即可直接得出同一主体患某病的结论 → 满足条件（2）→ 按诊断方法排除；若X浓度只是不能直接导出诊断结论的中间结果 → 不属于诊断方法。

## 关键要点
1. 客体审查先于新颖性、创造性；落入法2.2、法5、法25排除的一律不授权。
2. "违反法律"只能依据全国人大及其常委会的法律；仅实施受限、被滥用才违法、有副作用的药品均不排除；部分违法先通知删除。
3. 法5.2遗传资源排除需同时满足"违规获取或利用"和"依赖其遗传功能完成"。
4. 智力活动规则：主题名称外全部限定内容均为规则 → 法25排除；含技术特征 → 转法2.2审查。
5. 诊断方法看两条件（活体对象 + 直接目的为诊断结果或健康状况）；治疗方法含预防、免疫及治疗辅助方法，双重目的须限定为非治疗目的；排除的是方法本身，诊疗仪器、物质、药物可授权。

- **本指南**：第二部分第十章 化学领域 — 首次分离或提取的物质（§2.1）、医药用途（§2.2、§4.5.2）、微生物发明。

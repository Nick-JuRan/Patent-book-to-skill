# 第二部分 第十一章 关于中药领域发明专利申请审查的若干规定

## 核心要点
中药有效成分难以明确，产品靠"中药原料正名 + 用量配比 + 组方结构"表征；疾病可用中医的病或证、也可用西医的病表述且二者不完全对应；创造性以中医药理论（理、法、方、药，君臣佐使）分析组方结构判断。本章是一般规定在中药领域的特殊适用。

## 审查标准与框架

- **可授权客体**（§2.1）：产品——经产地加工得到的中药材、经炮制加工得到的中药饮片、中药组合物（中药组方/复方）、中药提取物、中药制剂；方法——中药材的栽培或产地加工方法、饮片的炮制方法、上述产品的制备方法或检测方法、中药产品的制药用途。

- **不可授权情形**（§2.2，法5.1、法25.1）：利用禁止入药的毒性中药材（关木通、广防己、青木香）→ 妨害公共利益（法5.1），但经炮制或配伍后有证据证明符合用药安全的可授权；天然形态存在的物质、中医药理论（阴阳五行、藏象学说）→ 科学发现（法25.1(1)），而用天然物质制成的中药材/饮片及其制备方法、制药用途不是科学发现；汤头口诀、歌诀 → 智力活动的规则和方法（法25.1(2)）；望闻问切 → 疾病的诊断方法，以治疗为目的的艾灸、拔罐、贴敷及第一章§4.3.2.1(2)所列情形 → 疾病的治疗方法（法25.1(3)）。

- **中药材名称**（§3.1.1，法26.3）：说明书一般应记载正名，须使本领域技术人员能够确认该中药材。名称在现有技术中无明确记载 → 必须记载植物基原、拉丁名、药用部位、性味归经、功效等，否则公开不充分；别名对应多种正名 → 结合说明书与现有技术的上述信息综合判断指代是否明确，指代不明确 → 公开不充分。

- **组成及用量配比**（§3.1.2，法26.3）：须记载中药原料组成**和**各原料用量配比关系（重量份、重量比例、重量百分比等）。配比决定组方结构和主次作用、直接影响疗效；未记载或记载不清楚 → 无法实现，公开不充分。

- **医药用途与实验数据**（§3.1.3，法26.3）：新的中药组合物须记载具体医药用途。本领域技术人员根据现有技术无法预测能实现该用途 → 须记载实验数据（实验室实验含动物实验，或临床治疗效果数据含临床医案、临床病例）。治疗中医病或证的：依据现有技术公开的病或证的治法治则、各药味的功效或作用不能预测 → 须给出实验数据；能够预测 → 即使无实验数据也不应据此认为公开不充分。

- **权利要求表达与支持**（§3.2，法26.4）：表达方式适用第十章§4.2.1；"由……制成"表示该组合物由所指组分作为中药原料制备而成（§3.2.1）。各原料用量配比应以说明书为依据；概括的配比范围若包含与说明书公开的药味配伍关系实质不同（组方结构实质不同）的方案，致不能预测均能解决技术问题并达到相同技术效果 → 得不到说明书支持（§3.2.2）。

- **新颖性：古方用量换算**（§4.1，法22.2）：对比文件为中医古方时先换算历代度量衡（汉制六铢为一分，四分为一两，即二十四铢为一两）；换算后配比落入发明范围 → 无新颖性。

- **新颖性：制药用途的病与证**（§4.2，法22.2）：同一疾病不同阶段有不同证型，同一证型可发生于不同疾病；须考量中医的病与证及其与西医的病或药物作用机理是否相同。
  - (1) 发明以中医的病限定，对比文件公开治疗该病某证型 → 证型限定的中医疾病通常属于该疾病的一种类型 → 破坏新颖性（气阴两虚型胸痹 ⊂ 胸痹）。
  - (2) 发明以西医病名表述，对比文件以中医病或证表述 → 病名相同其实质疾病不必然相同，只有疾病相同或实质相同才破坏新颖性（鼻鼽相当于过敏性鼻炎等 → 无新颖性）。
  - (3) 发明以中医的病限定，对比文件公开该中药的药物作用机理 → 机理针对的疾病与该中医病相同或实质相同 → 破坏新颖性（促进胰岛素分泌隐含治疗糖尿病 ⊂ 消渴病）。

- **中药组合物创造性的三个注意点**（§5.1，法22.3）：
  - 最接近的现有技术：考量"理、法、方、药"，从发明实质出发分析组方结构，选择技术领域、所要解决的技术问题、技术效果或用途最接近，和/或起主要作用的中药原料（主要药味、主药、君药）相同或相近者。
  - 区别特征：区别药味按主次分层（针对主病或主证的为主要药味，治疗兼证或次要症状的为次要药味）；组方结构不明晰或同层药味多时按功效或作用分类。
  - 显而易见性：站位本领域技术人员，从整体上判断现有技术是否存在该区别特征及将其用于最接近的现有技术解决该技术问题的技术启示。启示来源：最接近现有技术的其他部分、教科书、工具书、综述性文献中的药味加减信息，药味功效、用量用法、药理作用，疾病的病因病机、治法治则、常见病程变化和兼证。

- **加减方——中药原料变更的组方发明**（§5.1.1.1）：以已知方为基础方，主要药味不变，调整次要药味和/或药量。现有技术未给出将区别特征应用于基础方以解决其技术问题的技术启示且产生有益技术效果 → 有创造性；反之无。分型：药味增减——无启示 + 有益效果 → 有；药味替换——属于现有技术已知的相同功效药味替代且没有产生预料不到的技术效果 → 无（因肾毒性用土木香替代青木香为现有技术已知）；药量加减——不改变组方结构即主药不变的常规药量加减、无预料不到的技术效果 → 无（君药生地不变，仅调臣药麦冬、佐药白芍用量且未证明对比效果）。

- **合方发明**（§5.1.1.2）：两个及以上已知方合并使用或合方化裁。考量组合的技术启示、组合的难易程度、组合后的技术效果。无合方启示 + 有益效果 → 有创造性（银翘散合平胃散治病毒性肺炎，现有技术无平胃散治肺炎记载）；仅简单组合、效果只是各已知方效果的加和 → 简单的叠加，无创造性（加味六味地黄汤合甘麦大枣汤治更年期综合征，病因病机提示标本兼治合用且无实验数据）。

- **自组方发明**（§5.1.2）：不以已知方为基础直接遣药组方，或改变了已知方的主要药味。说明书须记载组方原则、组方结构或方解及足以证明技术效果的实验数据。分析方解后考量现有技术是否存在将各药味配伍以解决技术问题的技术启示；无启示 + 有益效果 → 有创造性（现有技术仅公开治子宫肌瘤的治法和常用单味药，未给出6味按主次配伍的启示）。

- **实用性**（§6，法22.4）：医生处方适用第十章§7.2；从动物体获取中药原料的方法（活牛摘牛黄、活熊取胆汁）属第五章§3.2.4动物体的非治疗目的的外科手术方法，无法在产业上使用 → 无实用性。

## 关键概念
- **中药组合物**：中药组方/复方，以中医药理论为指导、具有组方结构的多药味产品（§2.1、§5.1）
- **正名**：中药材规范名称，区别于异名、别名、俗称（§3.1.1）
- **用量配比**：各原料用量关系，决定组方结构和主次作用（§3.1.2）
- **组方结构 / 君臣佐使**：药味主次关系；主药（君药）改变即组方结构改变（§5.1）
- **证型**：同一疾病不同阶段的证候分型；中医的病 ⊃ 证型（§4.2）
- **中药原料变更的组方发明**：主药不变的药味增减、替换、药量加减（§5.1.1.1）
- **合方发明**：已知方合并使用或合方化裁（§5.1.1.2）
- **自组方发明**：无基础方直接遣药组方，或改变已知方主要药味（§5.1.2）

## 思维模型
- 把"正名 + 配比 + 组方结构"当作中药产品的结构式：缺一则说明书无法实现（法26.3）或权利要求超出支持（法26.4）。
- 创造性先问"主药变了没有"：不变 → 加减方，查有无加减/替换/合方启示及预料不到的效果；改变或无基础方 → 自组方，查方解、实验数据和配伍启示。
- 病与证按集合关系判新颖性：中医病包含其证型；中西医病须"相同或实质相同"；作用机理隐含的疾病可落入中医病范围。

## 反模式
- **配比一律写宽范围（如均1-50份）**：覆盖主次配伍实质不同的方案 → 不支持（§3.2.2）。
- **用自创名或多义别名记载药材且不给基原、拉丁名等**，或**只写组成不写配比** → 公开不充分（§3.1.1、§3.1.2）。
- **疗效可预测却因无实验数据认定公开不充分**：指南明确不应据此认定（§3.1.3）。
- **以古方单位不同、"对比文件仅公开某证型"或中西医病名字面差异直接下新颖性结论**：须换算比对、证型落入该病、判断疾病是否实质相同（§4.1、§4.2）。
- **把公知药对配伍、已知同功效替代、主药不变的常规药量微调当作创造性**：无预料不到的效果 → 无创造性（§5.1.1.1）；**合方仅效果加和** → 简单叠加（§5.1.1.2）。

## 实例演练
**药味增减 vs 药对配伍**（§5.1.1.1）：对比文件抗癫痫方11味（君药天麻、钩藤、僵蚕；臣药含白附子、当归；佐使柴胡、郁金），发明删白附子、当归、柴胡、郁金，增佐使药丹参成8味，证明疗效与已知方相当。被删药味功效与其余臣药不同，柴胡、郁金功效亦与丹参有差异，现有技术无法给出"删四增一仍疗效相当"的启示 → 有创造性。对比：治骨折方含乳香10-20份，发明仅加没药10-15份；乳香、没药同为活血化瘀药、常作药对配伍属公知常识 → 有动机增加同功效药味 → 无创造性。

## 关键要点
1. 药材写正名；无现有技术记载或别名多义时补植物基原、拉丁名、药用部位、性味归经、功效。
2. 组合物必须记载组成和用量配比；权利要求配比范围不得包含与说明书配伍关系实质不同的方案。
3. 疗效不可预测时必须给实验数据（实验室/动物/临床医案病例）；可预测则不因缺数据否定公开。
4. 用途新颖性先厘清集合关系：中医病 ⊃ 证型；中西医病须实质相同；古方对比先换算度量衡。
5. 创造性：按理法方药和主药选最接近的现有技术 → 区别药味按主次分层 → 从教科书、工具书、综述中的加减信息、病因病机、治法治则找启示；按主药是否改变区分加减方与自组方。
6. 未证明安全的禁用毒性药材、天然物质、中医理论、口诀、望闻问切、艾灸拔罐贴敷、活体取材方法均不授权。

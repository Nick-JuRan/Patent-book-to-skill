# 第二部分 第三章 新颖性

## 核心要点
判断一项权利要求是否"不属于现有技术且无抵触申请"（法22.2）：先划定现有技术的边界（基准日、公开方式、保密状态），再以"单独对比"把每项权利要求与每一份对比文件逐一比较；本章同时规定优先权、宽限期如何影响基准日，以及同样的发明创造禁止重复授权（法9）。

## 审查标准与框架

- **现有技术的界定**（§2.1，法22.5）：申请日（有优先权的，指优先权日）以前在国内外为公众所知的技术。两要件：处于能够为公众获得的状态 + 包含能使公众从中得知实质性技术知识的内容。
  - 时间界限（§2.1.1）：申请日当天公开的内容不属于现有技术。
  - 保密状态不属于现有技术，含受保密规定/协议约束，以及社会观念或商业习惯上应承担保密义务的"默契保密"；但负有保密义务的人违反规定、协议或默契泄露导致公开的，构成现有技术。

- **三种公开方式，均无地域限制**（§2.1.2）：
  - **出版物公开**（§2.1.2.1）：出版物 = 记载有技术或设计内容的独立存在的传播载体，且应当表明或有其他证据证明其公开发表/出版时间。不受地理位置、语言、获得方式、年代限制，与发行量、是否有人阅读、申请人是否知道无关；印有"内部资料"且确系在特定范围内发行并要求保密的除外。公开日：纸质以印刷日、视听资料以出版日、互联网资料以发布日（同时有纸质版的取能确定的最早日；发布日存疑可参考日志、搜索引擎索引、互联网档案馆、时间戳等）；只写年月/年份的以该月末日/12月31日为公开日；有疑义可要求提交人证明。
  - **使用公开**（§2.1.2.2）：制造、使用、销售、进口、交换、馈赠、演示、展出、招标投标等，使技术内容处于"公众想得知就能够得知"的状态即构成，不取决于是否有人实际得知；需破坏才能得知结构、功能的产品仍属使用公开；展台、橱窗内可阅读的图纸、照片、样本、样品亦属之。例外：未给出任何技术说明、致所属技术领域的技术人员无法得知其结构和功能或材料成分的产品展示。公开日 = 公众能够得知之日。
  - **以其他方式公开**（§2.1.2.3）：口头交谈、报告、讨论会发言以发生之日为公开日；公众可接收的广播、电视、电影以播放日为公开日。

- **抵触申请**（§2.2，法22.2）：任何单位或个人就同样的发明或实用新型，在申请日以前向专利局提出、并在申请日以后（含申请日）公布或公告的专利申请文件/专利文件。判断以其全文内容为准（权利要求书 + 说明书及附图）；包括由专利局在申请日之后（含）公布或公告的进入国家阶段的国际申请；仅限申请日以前提出的，同日申请不构成抵触申请（转法9）；抵触申请只损害新颖性，评价创造性时不予考虑（第四章§2.1）。

- **对比文件的公开内容**（§2.3）：以其公开的技术内容为准 = 明确记载的内容 + 对所属技术领域的技术人员而言隐含的且可直接地、毫无疑义地确定的内容；不得随意扩大或缩小。附图只有能直接地、毫无疑义地确定的技术特征算公开；由附图推测的内容、无文字说明仅从附图测量得出的尺寸及其关系不算。

- **审查原则**（§3、§3.1）：新颖性只有在具备实用性后才予以考虑。
  - **同样的发明或者实用新型**：技术领域、所解决的技术问题、技术方案和预期效果实质上相同。先比技术方案是否实质上相同；相同时再由本领域技术人员确定两者能否适用于相同技术领域、解决相同技术问题、具有相同预期效果。
  - **单独对比**：各项权利要求分别与每一项现有技术或抵触申请的相关技术内容单独比较；不得与几项现有技术的组合、或一份对比文件中多项技术方案的组合对比（创造性允许组合，第四章§3.1）。

- **审查基准**（§3.2，法22.2）：
  - **相同内容**（§3.2.1）：完全相同或仅是简单的文字变换 → 无新颖性；"相同"包括可直接地、毫无疑义地确定的内容（公开"钕铁硼磁体"即公开"主相为Nd₂Fe₁₄B、四方晶体结构的钕铁硼永磁合金"）。
  - **具体（下位）概念与一般（上位）概念**（§3.2.2）：下位概念的公开使上位概念限定的发明丧失新颖性（"铜制"破坏"金属制"），但不及于其他下位概念（不破坏铜以外的金属）；上位概念的公开不影响下位概念的新颖性（"金属"↛"铜"；"卤素"或"氟"↛"氯"）。
  - **惯用手段的直接置换**（§3.2.3）：区别仅是所属技术领域惯用手段的直接置换 → 无新颖性（螺钉固定→螺栓固定）。
  - **数值和数值范围**（§3.2.4，其余特征相同时）：(1) 对比文件的数值/范围落在权利要求范围内 → 破坏；(2) 部分重叠或有一个共同端点 → 破坏；(3) 对比文件范围的两个端点 → 破坏"离散数值且具有该两端点中任一个"的方案，不破坏两端点之间任一数值；(4) 权利要求的数值/范围落在对比文件范围内且无共同端点 → 不破坏。数值范围修改见第八章§5.2，通式化合物见第十章§5.1。
  - **包含性能、参数、用途或制备方法特征的产品权利要求**（§3.2.5）：统一问题——该特征是否隐含产品具有区别于对比文件产品的特定结构和/或组成。(1) 性能、参数：技术人员据此无法区分两产品 → 推定相同、无新颖性，除非申请人能根据申请文件或现有技术证明结构/组成不同；(2) 用途：由产品固有特性决定且未隐含结构/组成改变 → 无新颖性（"抗病毒的化合物X" vs "催化剂化合物X"）；用途表明结构/组成改变的作为限定特征必须考虑（"起重机用吊钩"与"钓鱼用吊钩"尺寸、强度不同，是不同产品）；(3) 制备方法：技术人员可以断定该方法必然导致不同的特定结构/组成 → 有新颖性；方法不同但结构、组成相同 → 无新颖性，除非申请人证明方法导致结构/组成不同，或带来不同性能从而表明结构/组成已改变。§3.2.1–3.2.5 同样适用于创造性判断中对该类特征是否相同的比对。

- **优先权**（§4，法29）：
  - **外国优先权条件**（§4.1.1，法29.1）：(1) 就相同主题在外国首次申请后又在中国提出；(2) 中国在后申请不迟于外国首次申请之日起十二个月（细则36：有正当理由的可在期限届满之日起2个月内请求恢复）；(3) 首次申请国/政府间组织与中国签有协议、共同参加国际条约或相互承认优先权。与首次申请审批结果无关，只要获得确定的申请日。
  - **相同主题**（§4.1.2）：技术领域、所解决的技术问题、技术方案和预期的效果相同，不要求文字记载或叙述方式完全一致；在后申请权利要求的技术方案只要已记载在首次申请中即可享有，不必出现在其权利要求书中（核实见第八章§4.6）。
  - **效力**（§4.1.3）：视为在首次申请日提出；优先权期间内他人提出的相同主题申请因失去新颖性不能授权。
  - **多项与部分优先权**（§4.1.4、§4.2.4，细则35.1）：可要求一项或多项优先权，期限自最早优先权日起算，须符合法31/细则39单一性。基础可分处不同国家（方案A享法国日、B享德国日；A"或"B写入同一权利要求亦可）。一项方案由两件首次申请分别记载的特征C、D组合而成且组合未在任一首次申请中记载 → 不享有优先权。在后申请新增改进方案（新增实施例的从属权利要求、符合单一性的独立权利要求）→ 审查员不得据此拒绝优先权或驳回；相同主题部分享优先权日，其余以在后申请日为申请日。本国场景：在后申请记载方案A及实施例a₁、a₂而仅a₁见于首次申请 → A和a₁享有优先权、a₂不享有；a₂提出时已是现有技术的应删除并将A限制在a₁支持的范围内；已在第一件在后申请中享有优先权的方案，在第二件在后申请中只能再要求中国首次申请的优先权。
  - **本国优先权**（§4.2，法29.2，细则35）：十二个月内以发明首次申请为基础提发明或实用新型，或以实用新型首次申请为基础提实用新型或发明。不得作为基础（细则35.2）：已要求外国或本国优先权的（要求过但未享有的除外）、已经被授予专利权的、按细则48提出的分案申请。中国首次申请自在后申请提出之日起视为撤回。

- **不丧失新颖性的宽限期**（§5，法24，细则33）：申请日以前六个月内发生下列情形之一的，不构成影响该申请的现有技术：(一) 国家出现紧急状态或非常情况时为公共利益目的首次公开；(二) 在中国政府主办或承认的国际展览会上首次展出；(三) 在规定的学术会议或技术会议上首次发表；(四) 他人未经申请人同意而泄露其内容。程序见第一部分第一章§6.3。
  - 宽限期 ≠ 优先权：公开后已成为现有技术，仅在期限内对申请人不视为破坏新颖性、创造性的现有技术，公开日不视为申请日；他人在公开日至申请日之间独立作出并先申请的，依先申请原则申请人不能取得专利权（他人也因该公开无新颖性）。
  - 再次公开：六个月内、申请前再次公开且不属于四种情形 → 丧失新颖性；属于四种情形 → 不丧失，但宽限期自第一次公开之日起算。紧急状态首次公开后他人再公开视为第(一)项；未经同意泄露后第三人再公开视为第(四)项。
  - 程序：(二)(三)项须按细则33.3提出声明并提交证明文件，否则不能享受（细则33.5）；(一)(四)项在收到通知书后才得知的，须在指定期限内答复并附证明文件，未按期提交不能享受（细则33.4及.5）。争议时主张法24效力的一方负举证责任。

- **对同样的发明创造的处理**（§6，法9，细则47）：同样的发明创造只能授予一项专利权；两个以上申请人分别申请的，授予最先申请的人。
  - **"同样的发明创造"**（§6.1，法64.1）：两件以上申请（或专利）中存在保护范围相同的权利要求。比较权利要求书与权利要求书，不比权利要求书与全部内容。说明书相同但一件保护产品、一件保护制造方法 → 不同发明创造；保护范围仅部分重叠（连续数值范围不完全相同）→ 不属于同样的发明创造。
  - 分流：在先申请构成抵触申请或已公开构成现有技术的 → 依法22.2/22.3审查，不用法9。
  - **处理方式**（§6.2，同日指申请日，有优先权的指优先权日）：两件申请、申请人相同 → 分别通知选择或修改；申请人不同 → 依细则47.1通知自行协商确定申请人；一件申请 + 一项已授权专利 → 通知修改。三种情形均：期满不答复 → 视为撤回；陈述/修改后仍不符合法9.1 → 驳回（两件申请时均驳回，协商不成亦驳回）。
  - **特例**（§6.2.2，法9.1，细则47.2）：同一申请人同日（仅指申请日）既申请实用新型又申请发明、实用新型专利权尚未终止且申请时分别作出说明的，可通过放弃实用新型专利权避免重复授权——答复时附交放弃书面声明，发明发授权通知书，实用新型专利权自公告授予发明专利权之日起终止。

## 关键概念
- **新颖性**：不属于现有技术，也没有任何单位或个人就同样的发明或实用新型在申请日以前提出申请并记载在申请日以后（含申请日）公布/公告的专利文件中（§2，法22.2）
- **现有技术**：申请日（优先权日）以前在国内外为公众所知的技术，须处于公众能够获得的状态并含实质性技术知识（§2.1，法22.5）
- **默契保密**：社会观念或商业习惯上被认为应当承担保密义务的情形，属保密状态（§2.1）
- **使用公开**：因使用导致技术方案公开或处于公众可以得知的状态，不取决于是否有人实际得知（§2.1.2.2）
- **抵触申请**：申请日前提出、申请日后（含）公布或公告的同样发明或实用新型的专利申请，仅损害新颖性（§2.2）
- **直接地、毫无疑义地确定**：对比文件隐含内容和附图特征被视为已公开的唯一标准（§2.3、§3.2.1）
- **单独对比**：每项权利要求与每一份对比文件的一个技术方案单独比较、禁止组合（§3.1）
- **相同主题**：技术领域、技术问题、技术方案和预期效果相同，不要求文字一致（§4.1.2）
- **宽限期（优惠期）**：申请日前六个月内法24四种公开不视为影响新颖性的现有技术（§5）
- **同样的发明创造（法9）**：两件以上申请/专利中保护范围相同的权利要求（§6.1）

## 思维模型
- 新颖性是"一对一"匹配：一项权利要求 vs 一份对比文件的一个技术方案；只要需要拼接两处内容才能得到权利要求，就已离开新颖性、进入创造性。
- 对比文件能"公开"什么，以本领域技术人员能否直接地、毫无疑义地确定为界；推测、测量附图、常识补充都不算公开。
- 概念与数值的方向是单向的：具体破坏一般、一般不破坏具体；对比文件的点/范围落入权利要求范围即破坏，权利要求落入对比文件宽范围（无共同端点）则不破坏——后者转入选择发明的创造性评价。
- 产品权利要求中的性能、参数、用途、方法特征都翻译成一句："它是否让产品的结构和/或组成不同于对比文件产品？"无法区分时举证责任在申请人。
- 宽限期只是"暂不计入现有技术"，优先权才是"把基准日前移"；两者效力不可混用。

## 反模式
- **组合多份对比文件或一份文件中多个方案评价新颖性**：违反单独对比原则（§3.1），组合只能用于创造性；反之**用抵触申请评价创造性**亦错（第四章§2.1）。
- **以申请日当天公开的文献或同日申请作为现有技术/抵触申请**：当天公开不属现有技术（§2.1.1）；同日申请走法9（§2.2、§6）。
- **从附图测量尺寸或据附图推测结构作为公开内容**（§2.3）。
- **以上位概念的公开否定下位概念，或认为权利要求窄范围落入对比文件宽范围即无新颖性**：方向错误（§3.2.2、§3.2.4(4)）。
- **申请人仅口头主张参数/方法特征带来结构差异而不举证**：技术人员无法区分时推定相同，须以申请文件或现有技术证明（§3.2.5）。
- **把宽限期当作优先权**：公开日不前移为申请日，他人在此期间先申请仍适用先申请原则（§5）。
- **审查员以在后申请新增了首次申请未记载的方案为由拒绝全部优先权或驳回**：应给予部分优先权（§4.1.4(3)）。
- **法9判断时拿权利要求与对方说明书全文比较**：只比权利要求与权利要求（§6.1）。

## 实例演练
**演练一（数值范围，§3.2.4）**：权利要求"二氧化钛光催化剂制备方法，干燥温度为40℃、58℃、75℃或100℃"；对比文件公开40℃～100℃，其余特征相同。对比文件范围的两个端点40℃、100℃直接破坏"40℃""100℃"两个并列方案的新颖性（规则(3)）；58℃、75℃位于两端点之间且无共同端点，不被破坏（规则(4)）。处理：指出40℃、100℃方案无新颖性；58℃、75℃方案转入选择发明的创造性评价。

**演练二（制备方法特征的产品 + 法9分流）**：权利要求"用X方法制得的玻璃杯"，对比文件"用Y方法制得的玻璃杯"。先问X方法是否必然使产品具有不同结构/组成：两杯结构、形状、构成材料相同 → 推定相同、无新颖性，除非申请人举证；X含对比文件没有的特定温度退火步骤且耐碎性明显提高 → 性能差异表明微观结构已变 → 具备新颖性（§3.2.5(3)）。若对比文件是同一申请人同日的另一申请且权利要求保护范围相同 → 按法9通知选择或修改（§6.2.1.1）；若其早一日提出 → 抵触申请，依法22.2评价（§6）。

## 关键要点
1. 基准日 = 申请日，有优先权的为优先权日；申请日当天公开的不算现有技术；三种公开方式均无地域限制。
2. 对比文件公开内容 = 明确记载 + 直接地、毫无疑义地确定的隐含内容；附图只算能直接确定的特征。
3. 新颖性只在具备实用性后审查；每项权利要求与每份对比文件单独对比，禁止组合。
4. 基准方向：文字变换/惯用手段直接置换 → 无新颖性；下位破坏上位、上位不破坏下位；对比文件数值落入权利要求范围、部分重叠、共同端点 → 破坏，权利要求落入对比文件宽范围且无共同端点 → 不破坏。
5. 性能、参数、用途、制备方法特征只在其隐含结构/组成差异时才赋予产品新颖性；无法区分时推定相同，由申请人举证。
6. 优先权要求相同主题（四要素相同，非文字一致）且记载于首次申请全文即可；跨首次申请拼合的方案不享优先权；宽限期六个月、法24四种情形、(二)(三)须声明并举证，且不改变申请日。
7. 法9只比权利要求与权利要求，"保护范围相同"才是同样的发明创造；在先申请已构成抵触申请或现有技术的用法22。

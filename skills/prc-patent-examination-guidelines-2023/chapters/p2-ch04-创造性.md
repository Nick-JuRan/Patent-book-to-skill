# 第二部分 第四章 创造性

## 核心要点
判断一项发明相对于现有技术是否同时具有"突出的实质性特点"（非显而易见）和"显著的进步"（有益的技术效果）（法22.3）；核心工具是站在"所属技术领域的技术人员"立场执行"三步法"，辅以预料不到的技术效果等因素防止低估、以"避免事后诸葛亮"防止主观。本章仅规定发明的创造性审查。

## 审查标准与框架

- **创造性的两个要件**（§2，法22.3）：与现有技术相比，发明有突出的实质性特点**和**显著的进步，缺一不可。
  - **突出的实质性特点**（§2.2）：对所属技术领域的技术人员来说，发明相对于现有技术是非显而易见的。技术人员在现有技术基础上仅仅通过合乎逻辑的分析、推理或者有限的试验可以得到 → 显而易见 → 不具备。
  - **显著的进步**（§2.3）：与现有技术相比能够产生有益的技术效果，如克服现有技术的缺点和不足、为解决某一技术问题提供不同构思的技术方案、代表某种新的技术发展趋势。
  - **现有技术的范围**（§2.1）：同法22.5及第三章§2.1；抵触申请的内容不属于现有技术，评价创造性时不予考虑。

- **所属技术领域的技术人员**（§2.4）：假设的"人"——知晓申请日或优先权日之前发明所属技术领域所有的普通技术知识；能够获知该领域中所有的现有技术；具有应用该日期之前常规实验手段的能力；**不具有创造能力**。若所要解决的技术问题能促使其到其他技术领域寻找技术手段，则也具有从该其他领域获知该日期之前相关现有技术、普通技术知识和常规实验手段的能力。目的：统一审查标准，避免审查员主观因素。

- **审查原则**（§3、§3.1）：只有在具备新颖性的条件下才考虑创造性；既审突出的实质性特点也审显著的进步；不仅考虑技术方案本身，还要考虑所属技术领域、所解决的技术问题和技术效果，将发明作为一个整体看待；与新颖性"单独对比"不同，可将一份或多份现有技术中的不同技术内容组合评价；独立权利要求具备创造性 → 一般不再审查其从属权利要求。

- **"三步法"——突出的实质性特点的判断方法**（§3.2.1.1，法22.3）：
  - **(1) 确定最接近的现有技术**：现有技术中与要求保护的发明最密切相关的一个技术方案。可以是：技术领域相同、所解决的技术问题/技术效果/用途最接近和／或公开发明技术特征最多的现有技术；或技术领域不同、但能够实现发明的功能且公开发明技术特征最多的现有技术。首先考虑技术领域相同或相近的，其中优先考虑与发明要解决的技术问题相关联的。
  - **(2) 确定发明的区别特征和发明实际解决的技术问题**：先找出与最接近现有技术的区别特征，再根据该区别特征**在要求保护的发明中所能达到的技术效果**确定实际解决的技术问题（= 为获得更好的技术效果而需对最接近的现有技术进行改进的技术任务）。审查员认定的最接近现有技术不同于说明书描述的 → 据此重新确定技术问题；发明的任何技术效果都可作为重新确定的基础，只要技术人员从说明书记载的内容能够得知；功能上彼此相互支持、存在相互作用关系的特征应整体考虑其效果；所有效果与最接近现有技术均相当时，技术问题为"提供一种可供选择的技术方案"。约束：重新确定的技术问题应与区别特征所能达到的技术效果相匹配，**不应被确定为区别特征本身，也不应包含对区别特征的指引或暗示**（例：指纹 + 掌纹等至少两种生物认证 vs 仅指纹 → 技术问题是"如何提高消费电子设备的用户账户安全性"，不是"如何增加掌纹等认证方式"）。
  - **(3) 判断要求保护的发明对本领域的技术人员来说是否显而易见**：从最接近现有技术和实际解决的技术问题出发，确定现有技术**整体上**是否存在技术启示——是否给出将区别特征应用到最接近现有技术以解决该技术问题的启示，使技术人员面对该问题时有动机改进并获得发明。存在启示 → 显而易见。通常认为存在技术启示的三种情况：(i) 区别特征为**公知常识**（本领域解决该重新确定的技术问题的惯用手段，或教科书、技术词典、技术手册等工具书披露的解决该问题的技术手段——铝作为轻质材料用于建筑构件已载于建筑标准）；(ii) 区别特征为**与最接近现有技术相关的技术手段**（同一份对比文件其他部分披露，且其在该部分所起的作用与区别特征在发明中的作用相同——氦气检漏装置）；(iii) 区别特征为**另一份对比文件披露的相关技术手段**，且作用相同（金属盘式制动器上冲洗灰尘的排水凹槽 → 石墨盘式制动器冲洗磨屑，性质相同的技术问题）。三种情况共同要件：手段已披露 + **作用相同**。

- **显著的进步的判断**（§3.2.2）：看是否具有有益的技术效果。四种通常认定情形：(1) 更好的技术效果（质量改善、产量提高、节约能源、防治环境污染等）；(2) 技术构思不同的技术方案，效果基本达到现有技术水平；(3) 代表某种新技术发展趋势；(4) 某些方面有负面效果，但其他方面有明显积极的技术效果。

- **几种不同类型发明的创造性判断**（§4）：按发明与最接近现有技术的区别特征的特点划分，仅具参考性，不要生搬硬套。
  - **开拓性发明**（§4.1）：全新的技术方案，技术史上未曾有过先例，开创新纪元 → 具备创造性（四大发明、蒸汽机、白炽灯、雷达、激光器、计算机汉字输入）。
  - **组合发明**（§4.2）：考虑组合后各特征在功能上是否彼此相互支持、组合难易程度、现有技术中是否存在组合的启示、组合后的技术效果。**显而易见的组合**：已知产品/方法简单组合或连接、各自以常规方式工作、总效果为各部分效果之总和、功能上无相互作用关系的简单叠加（带电子表的圆珠笔）；仅是公知结构的变型或处于常规技术继续发展范围内且无预料不到效果 → 均无创造性。**非显而易见的组合**：各特征功能上彼此支持并取得新的技术效果，或组合效果比各特征效果之总和更优越 → 具备创造性；每个单独特征是否已知不影响评价（深冷处理后不回火直接化学镀，省去工序且镀层耐磨耐蚀、基体稳定）。
  - **选择发明**（§4.3）：从现有技术公开的宽范围中有目的地选出现有技术未提到的窄范围或个体。**预料不到的技术效果是主要考虑因素**。无创造性：(1) 仅从已知可能性中选择/从具有相同可能性的方案中选一种（选用公知电加热法）；(2) 在可能的、有限的范围内选择具体尺寸、温度范围或其他参数，可由常规手段得到（惰性气体流速可常规计算）；(3) 可从现有技术直接推导出的选择（组分最低含量可从关系曲线推出）——均以无预料不到效果为前提。(4) 选择带来预料不到的技术效果 → 具备创造性。
  - **转用发明**（§4.4）：某一技术领域的现有技术转用到其他领域。考虑领域远近、是否存在技术启示、转用难易、是否需克服技术困难、转用效果。类似/相近领域间且无预料不到效果 → 无（柜子支撑→桌子）；产生预料不到效果或克服了原领域未曾遇到的困难 → 有（飞机主翼→潜艇副翼）。
  - **已知产品的新用途发明**（§4.5）：考虑新用途与现有用途技术领域的远近、新用途带来的效果。仅使用已知材料的已知性质 → 无（润滑油组合物同领域用作切削剂）；利用已知产品新发现的性质并产生预料不到效果 → 有（木材杀菌剂五氯酚→除草剂）。
  - **要素变更的发明**（§4.6）：考虑是否存在技术启示、技术效果是否可预料。要素关系改变（§4.6.1，形状、尺寸、比例、位置及作用关系变化）：未导致效果、功能、用途变化或变化可预料 → 无（刻度盘转/指针不动的"动静转换"）；预料不到效果 → 有（刀片斜角实现自动研磨）。要素替代（§4.6.2）：相同功能已知手段的等效替代、用已知最新研制的相同功能材料替代、用类似应用已知的公知材料替代，且无预料不到效果 → 无（液压马达替代电机）；产生预料不到效果 → 有。要素省略（§4.6.3）：省去后功能相应消失 → 无（涂料省去防冻剂）；省去零部件/工序后依然保持原有的全部功能，或带来预料不到效果 → 有。

- **判断创造性时需考虑的其他因素**（§5）：出现下列情形时审查员应予考虑，不应轻易作出不具备创造性的结论：
  - **解决了人们一直渴望解决但始终未能获得成功的技术难题**（§5.1）→ 具备创造性（冷冻"烙印"为牲畜无痛永久标记）。
  - **克服了技术偏见**（§5.2）：技术偏见 = 某段时间内、某技术领域中技术人员对某技术问题普遍存在的、偏离客观事实的认识，引导人们不去考虑其他可能性、阻碍研发。采用人们因技术偏见而舍弃的技术手段解决了技术问题 → 具备创造性（换向器表面制出粗糙细纹反而电流损耗更小）。
  - **取得了预料不到的技术效果**（§5.3）："质"的变化（新的性能）或"量"的变化（超出人们预期的想象），且技术人员事先无法预测或推理出来；既说明显著的进步，也反映非显而易见 → 具备创造性。
  - **在商业上获得成功**（§5.4）：成功由发明的技术特征直接导致 → 反映有益效果并说明非显而易见 → 具备创造性；由销售技术改进或广告宣传等其他原因所致 → 不能作为判断依据。

- **审查创造性时应当注意的问题**（§6）：
  - **创立发明的途径不影响评价**（§6.1）：历尽艰辛或唾手而得、偶然作出均不影响（碳黑3%误加为30%得到高强度耐磨轮胎橡胶）。
  - **避免"事后诸葛亮"**（§6.2）：审查员是在了解发明内容后判断，容易低估创造性；须牢记评价是由所属技术领域的技术人员依据申请日以前的现有技术与发明比较作出的。
  - **对预料不到的技术效果的考虑**（§6.3）：有预料不到的技术效果 → 不必再怀疑是否具有突出的实质性特点，可确定具备创造性；若按§3.2三步法已能判断非显而易见且有有益效果 → 具备创造性，此时不应强调是否有预料不到效果。
  - **对要求保护的发明进行审查**（§6.4）：评价对象是权利要求限定的技术方案**整体**，不是某一技术特征；对现有技术作出贡献的特征（产生预料不到效果的特征、体现克服技术偏见的特征）应写入权利要求，否则即使说明书有记载也不予考虑。

## 关键概念
- **创造性**：与现有技术相比，发明有突出的实质性特点和显著的进步（§2，法22.3）
- **突出的实质性特点**：对所属技术领域的技术人员而言相对于现有技术非显而易见（§2.2）
- **显著的进步**：与现有技术相比能够产生有益的技术效果（§2.3）
- **所属技术领域的技术人员**：假设的人，知晓申请日前本领域全部普通技术知识与现有技术、能运用常规实验手段、但无创造能力（§2.4）
- **显而易见**：技术人员在现有技术基础上仅通过合乎逻辑的分析、推理或有限的试验即可得到（§2.2）
- **最接近的现有技术**：现有技术中与要求保护的发明最密切相关的一个技术方案，三步法的基础（§3.2.1.1）
- **发明实际解决的技术问题**：为获得更好的技术效果而需对最接近现有技术进行改进的技术任务，由区别特征的效果确定（§3.2.1.1）
- **技术启示**：现有技术整体上给出的、将区别特征应用到最接近现有技术以解决该技术问题的启示（§3.2.1.1）
- **公知常识**：本领域解决该技术问题的惯用手段，或教科书、技术词典、技术手册等工具书披露的技术手段（§3.2.1.1）
- **技术偏见**：某段时间、某领域中普遍存在的、偏离客观事实的认识，阻碍人们考虑其他可能性（§5.2）
- **预料不到的技术效果**："质"的变化（新性能）或"量"的变化（超出预期），技术人员事先无法预测或推理（§5.3）

## 思维模型
- 把创造性评价看作"角色扮演"：先把自己降格为"不具有创造能力"的本领域技术人员，知识冻结在申请日之前，再问"面对这个技术问题，我有没有动机做出这个改进"。
- 三步法是一条因果链：最接近现有技术 → 区别特征 → 区别特征的效果 → 实际解决的技术问题 → 现有技术中是否有解决该问题的同作用手段；任何一环变了，后续全部重算。
- 技术启示 = "手段已披露" + "作用相同"。只找到区别特征出现在某文件里还不够，要看它在那里解决的是不是性质相同的技术问题。
- 当区别特征只是"选一个/换一个/去一个/挪一下/搬个领域/换个用途"时，问题收敛为："有没有预料不到的技术效果，或克服了原来没有的困难？"§5 的辅助因素是"防止低估"的安全阀，不是替代三步法的捷径。

## 反模式
- **用抵触申请评价创造性**：抵触申请不属于法22.3的现有技术（§2.1）。
- **把技术问题定义成区别特征本身或暗示区别特征**（"如何增加掌纹认证方式"）：技术问题须由区别特征的效果反推，不含对手段的指引（§3.2.1.1(2)）。
- **沿用说明书声称的技术问题，不基于审查员认定的最接近现有技术重新确定**（§3.2.1.1(2)）。
- **"特征拼图"式认定启示**：找到区别特征出现在某文件即认定有启示，未核实其在该文件中的作用与在发明中的作用是否相同（§3.2.1.1(3)）。
- **逐个特征评价创造性、忽略相互作用特征间的关系**：应针对权利要求方案整体评价（§3.2.1.1(2)、§6.4）。
- **以发明"来得容易"或属偶然发现否定创造性**（§6.1）；**以发明完成后的知识回看现有技术**——事后诸葛亮（§6.2）。
- **三步法已判定非显而易见后仍以"未证明预料不到效果"驳回**（§6.3）。
- **申请人把带来预料不到效果或克服技术偏见的特征只写在说明书里**：不写入权利要求则不予考虑（§6.4）。
- **以商业成功主张创造性却不能证明成功源于技术特征**：广告、销售技术导致的成功不作依据（§5.4）。
- **生搬硬套§4的发明类型**，或**只审突出的实质性特点不审显著的进步**（§4、§3.1）。

## 实例演练
**演练一（三步法走一遍，§3.2.1.2）**：权利要求：内燃机排气阀，主体由耐热镍基合金A制成，阀头部分涂敷镍基合金B覆层；解决阀头耐腐蚀、耐高温问题。对比文件1：同样排气阀，主体合金A，阀头覆层为另一种合金，并指出为适应高温、腐蚀环境覆层可选用耐高温、耐腐蚀合金。对比文件2：镍基合金B对极恶劣腐蚀环境和高温耐受性优异，可用于发动机排气阀。
- (1) 对比文件1技术领域相同、技术问题相同、公开特征最多 → 最接近的现有技术。
- (2) 区别特征 = 覆层材料限定为镍基合金B，效果是更好适应高温、腐蚀环境 → 实际解决的技术问题："如何使排气阀更好地适应高温和腐蚀性工作环境"（不写成"如何选用合金B"）。
- (3) 对比文件2披露合金B可用于排气阀且起提高耐腐蚀、耐高温作用，与其在发明中的作用相同 → 情形(iii)，存在技术启示，技术人员有动机结合1与2 → 显而易见 → 不具备突出的实质性特点。

**演练二（选择发明，§4.3(4)）**：现有技术制备硫代氯甲酸，催化剂用量比公开为>0且≤100%（mol），实施例2%～13%，教导从2%起产率随用量提高，行业惯例也是加大用量。发明选择0.02%～0.2%，产率提高11.6%～35.7%并简化反应物处理。窄范围落入宽范围且无共同端点 → 有新颖性；现有技术趋势指向"加大用量"，发明反向选择极小用量却大幅提高产率，是技术人员事先无法预测的"量"的变化 → 预料不到的技术效果 → 具备创造性。对照：选用公知电加热法，无预料不到效果 → 不具备。

## 关键要点
1. 两要件同时满足：非显而易见（突出的实质性特点）+ 有益技术效果（显著的进步）；先有新颖性才审创造性；抵触申请不计入。
2. 一切判断以"所属技术领域的技术人员"为尺度：知识全、能常规试验、无创造能力、知识截止于申请日/优先权日。
3. 三步法顺序不可乱：定最接近现有技术（优先同领域且问题关联）→ 找区别特征并按其效果重定技术问题（不含手段指引）→ 看现有技术整体是否有"同作用"的技术启示（公知常识/同一文件其他部分/另一文件）。
4. 组合、选择、转用、新用途、要素变更类发明的分水岭：功能上是否相互支持、是否有预料不到的技术效果、是否克服了原领域没有的困难。
5. 长期渴望未解难题、克服技术偏见、预料不到效果、源于技术特征的商业成功——出现任一者时不得轻易否定创造性。
6. 评价针对权利要求限定的方案整体；贡献性特征须写入权利要求；避免事后诸葛亮，不因发明来得容易或偶然而降低评价。

## 判断规则

- 权利要求除主题名称外只有算法/规则 → 法25.1(2) 排除；含任一技术特征 → 法2.2 三要素（p2-ch09）。
- 医药用途"用于治疗…" → 法25.1(3) 不授权；"制备治疗 Y 病药物的应用" → 可授（p2-ch10）。
- 下位公开破坏上位新颖性，反之不然；数值范围落入、共同端点、重叠 → 无新颖性，完全落在对比范围内且无共同端点 → 有（p2-ch03）。
- 区别特征为公知常识 / 同一文件他处 / 另一文件且作用相同 → 显而易见；预料不到的技术效果 → 具备创造性（p2-ch04）。
- 修改不能从原记载直接地、毫无疑义地确定 → 超范围；答复中扩大独权、换主题、加权利要求 → 不接受（p2-ch08）。
- 无效程序中专利权人修改 → 只能删权利要求、删方案、进一步限定、改明显错误（p4-ch03）。
- 无效请求人不回执且不出席 → 视为撤回；专利权人不出席 → 缺席审理（p4-ch04）。
- 实用新型创造性引三篇以上或跨领域 → 须论证"简单的叠加"或明确启示（p4-ch06）。
- 外观设计转用、拼合、替换 → 无明显区别，除非独特视觉效果（p4-ch05）。

## 两个决策树

**客体**：① 法5（违法、违德、害公、违规遗传资源）→ 不授权 ② 法25 六类（智力活动规则看"仅仅涉及"，诊断方法看"活体 + 直接结论"，治疗方法看目的）→ 排除 ③ 法2.2 三要素不齐 → 非技术方案 ④ 通过 → 审三性。

**修改能否接受**：① 超出原记载（法33）→ 否 ② 实审须针对通知书缺陷 / 复审仅限消除驳回缺陷 / 无效只做减法 → 不符则否 ③ 克服缺陷且无新缺陷 → 接受。

## 失权信号

- 申请日将满 3 年未提实审请求；一通 4 个月 / 再通 2 个月临近无人处理。
- 优先权副本 16 个月未交；宽限期只声明未举证。
- 年费进入滞纳期；登记手续 2 个月将届满。
- 无效请求后 1 个月补证期将过；收到决定近 3 个月未起诉。
- PCT 优先权日起 30 个月将届满未办进入手续；在中国完成的发明未经保密审查（法19）就向外国申请。
- 实用新型准备维权或开放许可但没有评价报告。

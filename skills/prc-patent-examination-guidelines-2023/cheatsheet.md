## 判断规则

- 权利要求除主题名称外只有算法/规则 → 法25.1(2) 排除；含任一技术特征 → 转法2.2 三要素（p2-ch09）。
- 医药用途写成"用于治疗…" → 法25.1(3) 不授权；写成"制备治疗 Y 病药物的应用" → 可授（p2-ch10）。
- 对比文件公开下位概念 → 上位无新颖性；公开上位 → 下位仍有（p2-ch03）。
- 数值范围：落入、共同端点、重叠 → 无新颖性；权利要求范围完全落在对比范围内且无共同端点 → 有新颖性（p2-ch03）。
- 区别特征是公知常识 / 同一文件他处 / 另一文件披露且作用相同 → 显而易见；有预料不到的技术效果 → 可直接认定具备创造性（p2-ch04）。
- 修改内容不能从原记载直接地、毫无疑义地确定 → 超范围（法33）；答复中扩大独权、换主题、加权利要求 → 即使不超范围也不接受（p2-ch08）。
- 无效程序中专利权人的修改 → 只能删权利要求、删技术方案、进一步限定、改明显错误（p4-ch03）。
- 无效请求人不回执且不出席口审 → 视为撤回；专利权人不出席 → 缺席审理（p4-ch04）。
- 实用新型创造性引用三篇以上或跨领域对比文件 → 须先论证"简单的叠加"或明确启示（p4-ch06）。
- 外观设计对比属转用、拼合、替换 → 视为有启示、无明显区别，除非产生独特视觉效果（p4-ch05）。
- 汇单缺申请号或费用名称、设取款密码、金额不足 → 视为未办理缴费手续（p5-ch02）。
- 邮寄申请以寄出邮戳日为申请日；邮戳缺失或不清 → 以收到日为申请日（p5-ch03）。
- PCT 国际公布文本未指定中国 → 没有效力；进入声明未指明的国际阶段修改 → 视为放弃（p3-ch01）。
- 申请人自身引起的延迟（逾期答复、延期、恢复） → 从授权延迟补偿天数中扣除（p5-ch09）。
- 实用新型 / 外观设计开放许可或维权 → 先拿结论正面的专利权评价报告（p5-ch11、p5-ch10）。

## 三个决策树

**客体**：① 属法5（违法、违德、害公；违规遗传资源）？→ 不授权 ② 属法25 六类？智力活动规则看"仅仅涉及"，诊断方法看"活体 + 直接结论"，治疗方法看目的 → 排除 ③ 法2.2 三要素齐？否 → 不是技术方案 ④ 通过 → 审实用性、新颖性、创造性。

**修改能否接受**：① 超出原记载范围（法33）？是 → 不接受 ② 阶段限制——实审须针对通知书缺陷（细则57.3）；复审仅限消除驳回缺陷（细则66）；无效只做减法 → 不符则不接受 ③ 克服了缺陷且未引入新缺陷 → 接受。

**逾期怎么办**：① 期限类型——法定不可延长，指定可延长 ② 已过期 → 是否四类不可恢复期限 ③ 否 → 不可抗拒事由（2 个月且 2 年内）或正当理由（2 个月 + 恢复费），同时补办手续 ④ 恢复期也过 → 失效处理。

## 失权信号

- 申请日将满 3 年而未提实审请求或未缴实审费。
- 审查意见通知书 4 个月 / 2 个月答复期临近无人处理。
- 优先权副本 16 个月未交；宽限期只声明未举证。
- 年费应缴日已过，进入 6 个月滞纳期。
- 授权通知已到，2 个月登记手续期将届满。
- 无效请求提出后 1 个月补证期将过，证据尚未补齐。
- 收到复审 / 无效决定已近 3 个月未起诉。
- PCT 优先权日起 30 个月将届满未办进入手续。
- 在中国完成的发明准备直接向外国申请而未做保密审查（法19）。
- 实用新型准备维权或开放许可但没有评价报告。
- 邮寄递交但邮戳不清，申请日可能改为收到日。

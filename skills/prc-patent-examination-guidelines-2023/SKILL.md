## 核心规则与判断工具（第二部分 实质审查）

**客体门槛：先问是不是技术方案，再问是否被排除（p2-ch01）**
- 法2.2 技术方案三要素：技术问题 + 利用自然规律的技术手段 + 技术效果；缺一即不是专利保护客体。
- 法5.1 三种排除（违反法律 / 社会公德 / 妨害公共利益）：仅"实施"被法律禁止的不属于违反法律（细则10）；可能有副作用或被滥用的不算妨害公共利益；部分内容违反的先通知删除。
- 法25 五类排除的判断：智力活动的规则和方法看是否"仅仅涉及"（含技术特征的整体方案不排除）；诊断方法要同时满足"以活体为对象 + 以获得诊断结果为直接目的"，得到中间结果的不算；治疗方法看目的，非治疗目的的美容、外科手术不在此列但可能因无实用性被拒；动植物品种排除但生产方法可授，"主要是生物学的方法"不可授。

**说明书与权利要求（p2-ch02）**
- 说明书三要件：清楚、完整、能够实现，标准人是"所属技术领域的技术人员"；五种不能实现的情形是驳回依据（第2.1.3节）。有益效果要能从技术特征直接得出或必然产生。
- 权利要求三要件：以说明书为依据（支持）、清楚、简要。功能性限定理解为覆盖所有能实现该功能的方式，因此说明书公开的方式不够时不被支持；上位概括和并列选择概括都要有支持；"厚""约"等用语可能不清楚。
- 独立权利要求 = 前序部分 + 特征部分，以最接近的现有技术划界；从属权利要求 = 引用部分 + 限定部分；多项从属权利要求择一引用且不得被另一多项从权引用。
- 开放式（包含/包括）与封闭式（由……组成）的含义不同，用途权利要求属于方法权利要求。

**新颖性：单独对比，逐项规则（p2-ch03）**
- 现有技术 = 申请日（优先权日）以前国内外公众能得知的技术，"以前"不含当日；三种公开方式（出版物、使用、其他）各有公开时间认定规则。
- 抵触申请：任何人（含申请人自己）在申请日前提出、申请日后（含当日）公布/公告的同样的发明或实用新型，以全文为准，只损害新颖性、不用于创造性。
- 审查基准：同样的发明或实用新型 = 技术领域、技术问题、技术方案、预期效果实质相同；每项权利要求只与一份对比文件的一个方案比；下位概念公开破坏上位概念的新颖性，反之不然；惯用手段的直接置换无新颖性。
- 数值范围四规则：对比文件公开的点值或范围落入权利要求范围 → 无新颖性；权利要求范围有共同端点或部分重叠 → 无新颖性；权利要求范围完全落在对比文件范围内且无共同端点 → 有新颖性（创造性另论）；权利要求是对比文件范围中的具体点 → 无新颖性。
- 法9 禁止重复授权：保护范围相同的权利要求不能并存；同日实用新型与发明的处理靠声明与放弃。宽限期（法24）四种情形须在申请时声明并在期限内提交证明。

**创造性：三步法 + 防事后诸葛亮（p2-ch04）**
- 三步法：① 确定最接近的现有技术（领域相同、问题/效果/用途最接近、公开特征最多）；② 确定区别特征和发明"实际解决的技术问题"（按区别特征的效果重新确定，不得把区别特征本身或其指引写进问题）；③ 判断现有技术整体是否给出把区别特征用到最接近现有技术上的技术启示——启示三来源：公知常识、同一对比文件其他部分、另一份对比文件，且"作用相同"。
- 可以组合多份对比文件（与新颖性不同）；抵触申请不用于评价创造性；发明整体考虑，功能上相互支持的特征一起看效果。
- 类型化判断：组合发明看功能上是否相互支持；选择发明、转用发明、已知产品新用途、要素变更（关系/替代/省略）都以"预料不到的技术效果"为分水岭。
- 四个辅助因素（长期渴望未解决的难题、克服技术偏见、预料不到的技术效果、商业成功须由技术特征导致）不应轻易否定创造性；发明过程的难易和偶然性不影响判断。

**实用性（p2-ch05）**
- 能够在产业上制造或使用 + 积极效果；先于新颖性和创造性审查；六种无实用性情形：无再现性（区别于成品率低）、违背自然规律、利用独一无二的自然条件、非治疗目的的外科手术方法、测量人体极限状态的方法、无积极效果。

**单一性与分案（p2-ch06）**
- 单一性 = 相同或相应的"特定技术特征"（对现有技术作出贡献的特征），必须先看现有技术再判断；六种合案方式（产品与专用制造方法、产品与用途、方法与专门设计的设备等）；权1被否定后其余独权要重新判断。
- 分案不得超出原申请记载的范围，沿用原申请日和优先权日；提出时机受原申请状态限制，分案再分案的递交日另有规则。

**检索与实审程序（p2-ch07、p2-ch08）**
- 检索先定基本检索要素（领域、问题、手段、效果），初步 → 常规 → 扩展三阶段，中止检索前须覆盖最低限度数据库；检索报告用 X/Y/E 标注对比文件。
- 实审三原则：请求原则、听证原则（驳回所依据的事实理由证据必须已通知并给过陈述机会）、程序节约原则。审查文本以最后一次合法修改为准；主动修改只能在提出实审请求时或收到进入实审通知起三个月内。
- 一通答复期四个月，再通两个月；答复时的修改须针对通知书指出的缺陷，且不得超出原记载范围（法33）；扩大独权范围、换主题、加新权利要求即使不超范围也不接受。逾期不答复视为撤回，可依细则6请求恢复。
- 驳回须满足细则59情形且已听证；授权前审查员可依职权改明显文字错误但不得触及保护范围；复审请求先经原审查部门前置审查。

**领域专章（p2-ch09、p2-ch10、p2-ch11）**
- 计算机程序：客体两步——先法25.1(2) 是否仅为智力活动规则，再法2.2 三要素；含算法或商业规则特征的申请把这些特征与技术特征"整体考虑"，看是否"功能上彼此相互支持、存在相互作用关系"；权利要求四件套（方法、装置/程序模块、存储介质、计算机程序产品）。
- 化学：结构不明的产品可用参数/制法表征但新颖性推定不利于申请人；补交实验数据应予审查，但所证明的效果须能从原申请公开内容得到；医药用途写成"制备治疗Y病药物的应用"避开法25.1(3)；组合物开放式/封闭式含义不同；化合物创造性看结构相近 + 预料不到的效果；生物材料公众不能得到的须按细则27保藏；遗传资源须披露直接来源和原始来源。
- 中药：说明书用中药材正名并公开用量配比；病与证的新颖性按中医辨证体系判断；加减方/合方/自组方的创造性以理法方药、君臣佐使分层确定区别特征。

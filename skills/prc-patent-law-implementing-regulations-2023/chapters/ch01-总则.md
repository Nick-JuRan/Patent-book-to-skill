# 第一章 总则（第1–16条）

## 核心要点
本章是细则的"程序底座 + 术语字典"：手续形式与语言、递交日与送达日、期限计算与恢复、保密申请与出境保密审查，并界定专利法术语（违反法律、申请日、在中国完成、职务发明创造、发明人），另设诚实信用原则与专利权转移、许可备案、出质登记手续。

## 引入的框架
### 一、手续形式与语言（第2、3条）
- 各种手续以书面形式或国务院专利行政部门规定的其他形式办理；能有形表现内容且可随时调取查用的数据电文（电子形式）视为书面形式（第2条）。
- 提交的文件必须用中文；国家有统一规定的科技术语用规范词；外国人名、地名和无统一译文的术语须注明原文（第3条第1款）。
- 外文证件和证明文件：认为必要时可要求在指定期限内附送中文译文；期满未附送 → 视为未提交该证件（第3条第2款）。

### 二、递交日与送达日（第4条）
- 邮寄文件以寄出邮戳日为递交日；邮戳不清晰的以收到日为递交日，当事人能举证的除外（第4条第1款）。
- 电子提交以进入指定的特定电子系统之日为递交日（第4条第2款）。
- 送达可用电子、邮寄、直接送交或其他方式；已委托代理机构的送交代理机构，未委托的送交请求书指明的联系人（第4条第3款）。
- 邮寄送达自发出之日起满15日推定为收到日；能证明实际收到日期的以实际收到日为准（第4条第4款）。
- 应直接送交的文件以交付日为送达日（第4条第5款）。
- 地址不清无法邮寄的可公告送达，自公告之日起满1个月视为已送达（第4条第6款）。
- 电子送达以进入当事人认可的电子系统之日为送达日（第4条第7款）。

### 三、期限计算（第5条）
- 期限开始当日不计入，自下一日起算（第5条）。
- 以年或月计算的，最后一月的相应日为届满日；该月无相应日的取该月最后一日（第5条）。
- 届满日是法定休假日的，顺延至休假日后第一个工作日（第5条）。

### 四、权利恢复与期限延长（第6条）
- 路径一：因不可抗拒的事由延误法定、细则或指定期限致权利丧失 → 自障碍消除之日起2个月内且自期限届满之日起2年内请求恢复（第6条第1款）。
- 路径二：因其他正当理由延误 → 自收到国务院专利行政部门通知之日起2个月内请求恢复；延误复审请求期限的 → 自复审请求期限届满之日起2个月内（第6条第2款）。
- 两路径均须提交恢复权利请求书、说明理由、必要时附证明文件并补办权利丧失前应办手续；路径二还须缴纳恢复权利请求费（第6条第3款）。
- 请求延长指定期限须在届满前提交延长期限请求书、说明理由并办理手续（第6条第4款）。
- 法24、29、42、74条规定的期限不适用两条恢复路径（第6条第5款）。

### 五、保密申请与出境保密审查（第7–9条）
- 涉及国防利益需保密的申请由国防专利机构受理审查，国务院专利行政部门受理的应及时移交；未发现驳回理由的由国务院专利行政部门决定授予国防专利权（第7条第1款，法4）。
- 涉及国防以外的国家安全或重大利益需保密的发明/实用新型申请 → 及时决定按保密专利申请处理并通知申请人；其审查、复审、无效的特殊程序由国务院专利行政部门规定（第7条第2款，法4）。
- "在中国完成" = 技术方案的实质性内容在中国境内完成（第8条第1款，法19.1）。
- 出境申请保密审查三路径：(一) 直接向外国申请或向国外机构提交国际申请 → 事先请求并详细说明技术方案；(二) 先在中国申请再向外国申请 → 在向外国申请前请求；(三) 向国务院专利行政部门提交国际申请 → 视为同时提出保密审查请求（第8条第2、3款，法19.1）。
- 认为可能需保密的，自请求递交日起2个月内发出保密审查通知，复杂可延长2个月；发出通知后自请求递交日起4个月内作出是否保密的决定并通知，复杂可延长2个月（第9条）。

### 六、术语界定与原则（第10–14条）
- 违反法律的发明创造不包括仅其实施为法律所禁止的发明创造（第10条，法5.1）。
- 申请专利应遵循诚实信用原则，以真实发明创造活动为基础，不得弄虚作假（第11条，法20.1）。
- 申请日双轨：专利法所称申请日在有优先权时指优先权日，法28、42条情形除外；本细则所称申请日除另有规定外指法28条的申请日（第12条）。
- 执行本单位任务的职务发明创造三类：本职工作中作出的；履行本单位交付的本职工作之外的任务作出的；退休、调离或劳动、人事关系终止后1年内作出且与原本职工作或原单位分配任务有关的（第13条第1款，法6.1）。
- 本单位包括临时工作单位；物质技术条件指资金、设备、零部件、原材料或不对外公开的技术信息和资料等（第13条第2款，法6.1）。
- 发明人/设计人指对实质性特点作出创造性贡献的人；仅负责组织、为利用物质技术条件提供方便或从事其他辅助工作的人不是（第14条）。

### 七、专利权转移、许可备案与出质（第15条）
- 除依法10转让外，因其他事由转移专利权的凭证明文件或法律文书办理转移手续（第15条第1款，法10）。
- 实施许可合同自生效之日起3个月内备案（第15条第2款，法12）。
- 以专利权出质的由出质人和质权人共同办理出质登记（第15条第3款）。

### 八、依据与政策目标（第1、16条）
- 细则依专利法制定（第1条）。
- 专利工作贯彻党和国家知识产权战略部署，提升创造、运用、保护、管理和服务水平（第16条第1款）。
- 国务院专利行政部门应完整、准确、及时发布专利信息、提供基础数据、促进数据开放共享互联互通（第16条第2款，法21）。

## 关键概念
- 电子形式 — 可有形表现、随时调取的数据电文，视为书面形式（第2条）
- 递交日 — 邮寄为邮戳日，电子提交为进入指定系统之日（第4条第1、2款）
- 推定收到日 — 邮寄文件自发出之日起满15日，可被实际收到日证据推翻（第4条第4款）
- 公告送达 — 地址不清无法邮寄时的替代送达，公告满1个月视为送达（第4条第6款）
- 恢复权利 — 期限延误致权利丧失后按两路径请求恢复的程序（第6条第1、2款）
- 不可抗拒的事由 — 触发"障碍消除后2个月且届满后2年"免费恢复路径的原因（第6条第1、3款）
- 国防专利 / 保密专利申请 — 分别因国防利益、其他国家安全或重大利益而需保密的申请（第7条）
- 保密审查 — 在中国完成的发明/实用新型向外国申请前的必经审查（第8、9条）
- 在中国完成 — 技术方案实质性内容在中国境内完成（第8条第1款）
- 优先权日 — 有优先权时专利法所称申请日的默认含义，法28、42除外（第12条第1款）
- 执行本单位任务的职务发明创造 — 本职、交付任务、离职后1年内相关三类（第13条第1款）
- 发明人/设计人 — 对实质性特点作出创造性贡献的人，不含组织者与辅助人员（第14条）

## 思维模型
- 遇到"哪天算交、哪天算收"时想第4条：交看邮戳日/进入系统日，收看满15日推定、交付日、进入认可系统日或公告满1个月（第4条）。
- 遇到任何期限时想三步：次日起算 → 相应日或月末 → 休假日顺延（第5条）。
- 遇到期限已过时先问"能否恢复"再问"走哪条路"：先排除法24/29/42/74期限，再分不可抗拒事由（免费）与正当理由（缴费）（第6条）。
- 遇到出境申请时想"先保密审查再出境"：三路径皆须过第8条，并按第9条时限等待（第8、9条）。

## 反模式
- 只靠邮寄却邮戳模糊又无证明 → 递交日退为收到日，可能因此逾期（第4条第1款）。
- 从发文日起算或忘记"当日不计入" → 少算15天或1天（第4条第4款、第5条）。
- 届满后才请求延长指定期限 → 延长须在届满前提出，逾期只能走恢复（第6条第4款）。
- 错过优先权期限或新颖性宽限期后请求恢复 → 法24、29、42、74期限不可恢复（第6条第5款）。
- 在中国完成的技术方案未经保密审查直接向外国申请 → 违反第8条的路径要求（第8条第2款，法19）。
- 把仅做组织协调、提供设备的人列为发明人 → 不符合创造性贡献标准（第14条）。

## 实例演练
拟例：审查意见通知书发文日2024年9月16日，指定4个月答复。
1. 推定收到日：自发出之日起满15日 → 2024年10月1日（第4条第4款）。
2. 期限计算：10月1日不计入，自次日起算，以月计的相应日为2025年2月1日；该日属春节法定休假日，顺延至假期后首个工作日2025年2月5日（第5条）。若申请人举证实际于10月10日收到，则届满日改为2025年2月10日（第4条第4款）。
3. 延长：须在2025年2月5日前提交延长期限请求书（第6条第4款）。
4. 逾期未答复致申请视为撤回，视为撤回通知书发文日2025年3月5日 → 推定收到3月20日 → 以正当理由请求恢复的截止日为2025年5月20日，须提交请求书、说明理由、补交答复并缴纳恢复权利请求费（第6条第2、3款）。
5. 对照：若延误系不可抗拒事由所致，则自障碍消除之日起2个月内且不晚于2027年2月5日请求，免缴恢复费（第6条第1、3款）；若错过的是优先权期限（法29），则任何路径均不可恢复（第6条第5款）。

## 关键要点
1. 电子形式视为书面；文件用中文，外文证件译文逾期不交视为未提交（第2、3条）。
2. 递交日看邮戳日或进入系统日；送达日看满15日推定、交付日、公告满1个月或进入认可系统日（第4条）。
3. 期限自次日起算，年月按相应日，无相应日取月末，休假日顺延（第5条）。
4. 恢复两路径（免费/缴费）各有时限；法24/29/42/74期限不可恢复；延长须届满前申请（第6条）。
5. 在中国完成的发明/实用新型出境须经保密审查三路径之一，通知2（+2）个月、决定4（+2）个月（第8、9条）。
6. 职务发明创造含离职后1年内的相关发明；发明人须有创造性贡献；申请须诚实信用（第11、13、14条）。
7. 许可合同生效后3个月内备案；非转让的转移凭文书办手续；出质须共同登记（第15条）。

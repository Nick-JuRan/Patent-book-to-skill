# 第四章 专利申请的复审与专利权的无效宣告（第65–76条）

## 核心要点
复审围绕"消除驳回决定指出的缺陷"展开，请求人不答复即视为撤回；无效宣告是请求人主导的对抗程序：理由限于第69条封闭清单，补充理由证据仅有1个月，指定期限不得延长，请求人缺席视为撤回、专利权人缺席可缺席审理，撤回也不必然终止程序。

## 引入的框架

### 一、复审请求的提出、受理与撤回（第65、68条）
- 请求复审须提交复审请求书并说明理由，必要时附具证据（第65条第1款，法41.1）。
- 请求不符合法18.1（代理）或法41.1（3个月内请求）→ 不予受理，书面通知并说明理由（第65条第2款）。
- 请求书格式不合规 → 指定期限内补正；期满未补正 → 视为未提出（第65条第3款）。
- 决定作出前请求人可撤回复审请求（第68条第1款）；撤回 → 复审程序终止（第68条第2款）。

### 二、复审中的修改与审查结论（第66、67条）
- 修改时机限于提出复审请求时和答复复审通知书时，内容仅限于消除驳回决定或复审通知书指出的缺陷（第66条）。
- 复审后认为请求不符合规定，或申请存在其他明显违反规定的情形 → 通知请求人在指定期限内陈述意见（第67条第1款）。
- 期满未答复 → 复审请求视为撤回；陈述意见或修改后仍不符合规定 → 作出驳回复审请求的复审决定（第67条第1款）。
- 原驳回决定不符合规定，或修改后已消除原驳回决定和复审通知书指出的缺陷 → 撤销原驳回决定，继续审查程序（第67条第2款）。

### 三、无效宣告请求的提出与法定理由（第69条）
- 请求宣告无效或部分无效须提交请求书和必要证据一式两份（第69条第1款，法45）。
- 请求书须结合全部证据具体说明理由，并指明每项理由所依据的证据（第69条第1款）。
- 无效理由为封闭清单：不符合法2、19.1、22、23、26.3、26.4、27.2、33或细则11、23.2、49.1；属于法5、25情形；依法9不能取得专利权（第69条第2款）。

### 四、不予受理与一事不再理（第70条）
- 请求不符合法18.1或细则69 → 不予受理（第70条第1款）。
- 部门已就无效请求作出决定后，又以同样理由和证据再请求 → 不予受理（第70条第2款）。
- 以法23.3权利冲突为由请求外观设计无效但未提交证明权利冲突的证据 → 不予受理（第70条第3款）。
- 请求书格式不合规 → 指定期限内补正；期满未补正 → 视为未提出（第70条第4款）。

### 五、理由证据的补充、转送答复与期限刚性（第71、72、75条）
- 受理后，请求人可在提出请求之日起1个月内增加理由或补充证据；逾期 → 部门可以不予考虑（第71条）。
- 部门将请求书及有关文件副本送交专利权人，要求其在指定期限内陈述意见（第72条第1款）。
- 双方应在指定期限内答复转送文件通知书或无效宣告请求审查通知书；期满未答复 → 不影响审理（第72条第2款）。
- 无效审查程序中部门指定的期限不得延长（第75条）。

### 六、专利权人在无效程序中的修改（第73条）
- 发明、实用新型专利权人可修改权利要求书，但不得扩大原专利保护范围（第73条第1款）。
- 在修改后的权利要求基础上维持有效或宣告部分无效 → 公告修改后的权利要求（第73条第1款）。
- 发明、实用新型不得修改说明书和附图；外观设计不得修改图片、照片和简要说明（第73条第2款）。

### 七、口头审理、撤回与程序终止（第74、76条）
- 依当事人请求或案情需要，部门可决定口头审理（第74条第1款）。
- 决定口头审理 → 发出口头审理通知书告知日期地点；当事人在通知书指定期限内答复（第74条第2款）。
- 请求人期限内未答复且不参加口头审理 → 无效请求视为撤回；专利权人不参加 → 可缺席审理（第74条第3款）。
- 决定作出前请求人可撤回无效请求（第76条第1款）。
- 撤回或视为撤回 → 审查程序终止；但部门认为依据已进行的审查能够作出无效或部分无效决定的 → 不终止（第76条第2款）。

## 关键概念
- 复审通知书 — 部门指出缺陷并要求指定期限内陈述意见的文书，也是第二个修改时机（第67条）。
- 消除缺陷式修改 — 复审中修改的边界：仅针对驳回决定或复审通知书指出的缺陷（第66条）。
- 视为未提出 — 请求书格式缺陷期满未补正的后果（第65条第3款、第70条第4款）。
- 撤销原驳回决定 — 复审成功的结果，回到审查程序而非直接授权（第67条第2款）。
- 无效宣告请求的理由 — 第69条第2款的封闭清单，清单外瑕疵不构成无效理由（第69条第2款）。
- 一事不再理 — 决定后以同样理由和证据再请求 → 不予受理（第70条第2款）。
- 权利冲突证据 — 以法23.3请求外观设计无效的受理前提（第70条第3款）。
- 1个月补充期 — 自提出无效请求之日起增加理由、补充证据的窗口，逾期可不予考虑（第71条）。
- 不得扩大原专利的保护范围 — 无效中修改权利要求书的实质边界（第73条第1款）。
- 缺席审理 — 专利权人不参加口头审理时部门可径行审理（第74条第3款）。

## 思维模型
- 复审是"对驳回决定的回应"而非重新申请：修改只能针对已指出的缺陷，成功结果也只是撤销驳回、回到审查（第66、67条）。
- 沉默后果不对称：无效请求人不答复口头审理通知且不到场 → 视为撤回；专利权人不答复 → 不影响审理、可缺席审理（第72、74条）。
- 节奏刚性：1个月补充窗口加指定期限不得延长，要求请求人在提出请求时就备齐理由和证据（第71、75条）。
- 撤回不是"安全阀"：审查已足以得出无效或部分无效结论时，撤回不终止程序，以和解换撤回须算好时点（第76条第2款）。

## 反模式
- 复审时借修改扩大或改写权利要求、引入与驳回理由无关的改动 → 超出允许的修改范围（第66条）。
- 无效请求书只堆证据、不指明每项理由对应的证据 → 不符合第69条 → 不予受理（第69条第1款、第70条第1款）。
- 以法23.3为由请求外观设计无效却不附权利冲突证据 → 不予受理（第70条第3款）。
- 受理后超过1个月才补充关键对比文件或新增理由 → 部门可以不予考虑（第71条）。
- 专利权人在无效程序中修改说明书、附图或外观设计图片 → 不允许；只能在不扩大范围内修改权利要求书（第73条）。
- 在无效程序中申请延长答复期限 → 不得延长（第75条）。

## 实例演练
拟例：甲于2024-03-01对乙的实用新型专利提出无效宣告请求，理由为法22.3，附证据A、B一式两份并逐项对应，获受理。3月20日甲增加法26.4理由并补交证据C → 在1个月内，应予考虑；4月15日再补交证据D → 逾期，可以不予考虑（第71条）。乙在指定期限内将从属权利要求2的特征并入权利要求1 → 缩小范围，允许；同时想改正说明书笔误 → 不允许（第73条）。乙请求延长答复期限 → 不得延长（第75条）。口头审理通知书发出后，甲未在指定期限内答复也未出席 → 请求视为撤回；但部门认为基于已进行的审查已能作出部分无效决定 → 不终止程序，在修改后的权利要求基础上宣告部分无效并公告修改后的权利要求（第74条第3款、第76条第2款、第73条第1款）。甲事后以同样理由和证据再次请求 → 不予受理（第70条第2款）。

## 关键要点
1. 复审请求格式缺陷不补正 → 视为未提出；复审通知不答复 → 视为撤回（第65、67条）。
2. 复审修改只能消除驳回决定、复审通知书指出的缺陷（第66条）。
3. 无效理由是第69条第2款的封闭清单，请求书须指明理由与证据的对应关系（第69条）。
4. 补充理由和证据只有自提出请求之日起1个月；无效程序指定期限不得延长（第71、75条）。
5. 同样理由和证据不能重复请求；外观设计权利冲突理由须附证据（第70条）。
6. 专利权人只能在不扩大保护范围内修改权利要求书，不得改说明书、附图、图片（第73条）。
7. 请求人缺席口头审理视为撤回，专利权人缺席可缺席审理；撤回后仍可能作出无效决定（第74、76条）。

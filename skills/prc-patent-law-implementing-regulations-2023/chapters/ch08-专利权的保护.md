# 第八章 专利权的保护（第95–105条）

## 核心要点
本章是专利法第65、68、70条行政保护的程序落地：哪级部门能处理和调解（第95、96条）、案件归谁管（第97条）、遇无效宣告、权属纠纷或法院保全时程序如何中止与恢复（第98、103–105条）、专利标识与假冒专利的边界（第99、101条）、不诚信申请与虚假开放许可的罚则（第100条）、行政调解的受案范围（第102条）。全章无实体侵权判定规则，只回答"谁来管、怎么管、何时停"。

## 引入的框架

### 一、处理机关层级与全国重大案件（第95、96条）
- 有权处理和调解专利纠纷的只有两级：省级管理专利工作的部门；专利管理工作量大且有实际处理能力的地级市、自治州、盟、地区及直辖市辖区的部门（第95条，法65、70）。
- "在全国有重大影响"的四种情形：涉及重大公共利益；对行业发展有重大影响；跨省级区域的重大案件；国务院专利行政部门认为可能有重大影响的其他情形（第96条第1款，法70.1）。
- 向国务院专利行政部门请求处理但不属于上述情形 → 可被指定给有管辖权的地方部门处理（第96条第2款）。

### 二、地域管辖与管辖冲突（第97条）
- 管辖连接点仅两个：被请求人所在地、侵权行为地（第97条第1款）。
- 多个部门有管辖权 → 当事人任选其一；同时向多个部门请求 → 最先受理者管辖（第97条第2款）。
- 管辖争议 → 共同上级管理专利工作的部门指定；无共同上级 → 国务院专利行政部门指定（第97条第3款）。

### 三、程序中止的三种触发与统一含义（第98、103–105条）
- 侵权处理中止：被请求人的无效宣告请求已被国务院专利行政部门受理 → 可请求管理专利工作的部门中止处理；中止理由明显不能成立 → 可不中止（第98条，法45）。
- 权属纠纷中止：申请权或专利权归属纠纷已请求调解或已起诉 → 可请求国务院专利行政部门中止有关程序；须提交请求书说明理由并附写明申请号或专利号的受理文件副本；理由明显不能成立可不中止（第103条第1、2款）。
- 恢复与延长：调解书或判决生效后当事人应办理恢复手续；自请求中止之日起1年内未结案需继续中止 → 须在该1年内请求延长；期满未请求 → 自行恢复（第103条第3款）。
- 保全中止：法院裁定对申请权或专利权保全 → 国务院专利行政部门于收到写明申请号或专利号的裁定书和协助执行通知书之日中止；保全期满未裁定续保 → 自行恢复（第104条）。
- "中止有关程序"的固定内容：暂停初审、实审、复审、授权、无效宣告五项程序，以及放弃、变更、转移专利权或申请权、质押、期限届满前终止等手续（第105条）。

### 四、专利标识与假冒专利（第99、101条）
- 依法第16条标注专利标识须采用国务院专利行政部门规定的方式；不符合 → 县级以上负责专利执法的部门责令改正（第99条，法16）。
- 假冒专利的五类行为：(一) 在未授权产品或包装上标注专利标识、无效或终止后继续标注、未经许可标注他人专利号；(二) 销售第(一)项产品；(三) 在说明书等材料中把未授权技术或设计称为专利技术或设计、把申请称为专利、未经许可使用他人专利号致公众误认；(四) 伪造或变造专利证书、专利文件、专利申请文件；(五) 其他使公众误认为专利技术或设计的混淆行为（第101条第1款，法68）。
- 存货例外：终止前依法在专利产品、依专利方法直接获得的产品或包装上标注，终止后继续许诺销售、销售该产品 → 不属于假冒（第101条第2款）。
- 善意销售者：不知是假冒专利产品且能证明合法来源 → 仅由县级以上负责专利执法的部门责令停止销售（第101条第3款，法68）。

### 五、不诚信行为的处罚（第100条）
- 申请人或专利权人违反第11条（申请须以真实发明创造为基础）或第88条（不得以虚假材料、隐瞒事实作开放许可声明或获年费减免）→ 县级以上负责专利执法的部门警告，可并处10万元以下罚款（第100条，法20）。

### 六、行政调解的受案范围（第102条）
- 除法第65条侵权纠纷外，应请求可调解五类：申请权与专利权归属；发明人、设计人资格；职务发明奖励报酬；发明申请公布后授权前使用未付适当费用；其他专利纠纷（第102条第1款，法65）。
- 临时保护期使用费纠纷 → 只能在授权之后请求调解（第102条第2款，法13）。

## 关键概念
- 管理专利工作的部门 — 地方政府中处理、调解专利纠纷的机关，仅省级和有条件的地市级有处理权（第95条）。
- 负责专利执法的部门 — 县级以上查处标识违规、假冒专利和不诚信行为的机关，与前者概念不同（第99–101条）。
- 在全国有重大影响的专利侵权纠纷 — 由国务院专利行政部门直接处理的四类案件（第96条第1款）。
- 最先受理 — 多头请求时确定唯一管辖部门的规则（第97条第2款）。
- 指定管辖 — 管辖争议由共同上级或国务院专利行政部门指定；非重大案件由后者指定地方处理（第96条第2款、第97条第3款）。
- 中止有关程序 — 暂停五项审查授权程序及放弃、变更、转移、质押、终止等手续的统称（第105条）。
- 自行恢复 — 中止满1年未延长或保全期满未续 → 无需申请即恢复程序（第103条第3款、第104条）。
- 假冒专利 — 以标注、表述、伪造等手段使公众误认未授权技术或设计为专利的五类行为（第101条第1款）。
- 合法来源 — 善意销售者仅被责令停止销售的证明要件（第101条第3款）。

## 思维模型
- 管辖三问依次过滤：谁能管（第95条层级）→ 在哪管（第97条连接点与最先受理）→ 是否上收（第96条四类重大影响，不符则退回地方）。
- 中止是防程序空转的阀门：三种触发（无效受理、权属纠纷、法院保全）、两类结束（当事人办恢复或部门自行恢复）、一个共同例外（理由明显不能成立可不中止）（第98、103、104条）。
- 假冒专利看"权利状态 × 时间点"：授权前、无效后、终止后的标注和表述均为假冒，唯一豁免是终止前已合法标注的存货继续销售（第101条第1、2款）。

## 反模式
- 普通侵权案直接请求国务院专利行政部门处理 → 会被指定回地方（第96条第2款）。
- 同时向多个部门请求以求择优 → 只由最先受理者管辖（第97条第2款）。
- 以"已提无效"主张必须中止 → 须已被受理，且理由明显不能成立时可不中止（第98条）。
- 权属纠纷中止满1年未请求延长 → 程序自行恢复（第103条第3款）。
- 申请阶段即在产品或宣传中称"专利产品""专利技术" → 假冒专利（第101条第1款第(三)项）；终止后继续标注新产品同样假冒，仅存货可售（第101条第1、2款）。

## 实例演练
拟例：甲持实用新型专利，乙公司（住所地A市）制造并在B市销售落入权利要求的产品，两市部门均属第95条有处理权的地市级部门。甲可任选A市（被请求人所在地）或B市（侵权行为地）请求处理，两地同时请求则由最先受理者管辖（第97条第1、2款）。乙提出无效宣告请求获受理后请求中止，部门认为其证据与授权阶段已克服的相同、理由明显不能成立，决定不中止（第98条）。另查明乙在一款仍在申请中的产品上印有"专利产品" → 构成第101条第1款第(三)项假冒，由县级以上负责专利执法的部门依法第68条处理；经销商丁不知情且能出示进货合同和发票 → 仅责令停止销售（第101条第3款）。若甲自己的标识格式不符合规定方式，也会被责令改正（第99条第2款）。

## 关键要点
1. 有权处理和调解的只有省级与有能力的地市级部门；四类全国重大案件归国务院专利行政部门，不符合则指定地方（第95、96条）。
2. 管辖看被请求人所在地或侵权行为地；多头请求由最先受理者管辖；争议由共同上级或国务院专利行政部门指定（第97条）。
3. 中止三触发：无效受理（第98条）、权属纠纷（第103条）、法院保全（第104条）；权属中止满1年须延长否则自行恢复。
4. 中止＝暂停审查、复审、授权、无效五项程序＋放弃、变更、转移、质押、终止等手续（第105条）。
5. 标识须按规定方式，违规责令改正（第99条）；假冒五类、存货例外、善意销售者仅停止销售（第101条）。
6. 违反诚信申请或虚假开放许可 → 警告并可处10万元以下罚款（第100条）。
7. 可调解五类纠纷；临时保护期使用费纠纷须授权后才能请求调解（第102条）。

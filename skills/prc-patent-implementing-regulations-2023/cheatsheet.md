## 决策规则

- 文件想按"当天"算递交 → 邮寄看邮戳日、电子看进入系统日；专利局文件对你则自发文日满15日推定送达（第4条）。
- 耽误的是宽限期、优先权期限、专利权期限或诉讼时效 → 不可恢复；其余先看不可抗拒（2个月 + 2年内）再看正当理由（2个月 + 费）（第6条）。
- 技术方案实质内容在中国完成 → 出境前保密审查；直接提 PCT 到专利局视为已请求（第8、9条）。
- 同日双报 → 申请时分别声明，授权前放弃实用新型；不放弃 → 驳回，不答复 → 视为撤回（第47条）。
- 想分案 → 原申请尚在审且未过登记期限；驳回/撤回/视为撤回后 → 不能（第48条）。
- 实审驳回只能引第59条清单；初审明显缺陷按三份清单（第50、59条）。
- 无效程序中专利权人 → 只能缩小权利要求；请求人 → 1个月内补齐理由证据，指定期限不延长（第71、73、75条）。
- 授权延迟补偿 → 申请日满4年且实审请求日满3年后才有；双报换取的发明 → 不补（第78条）。
- 开放许可 → 授权公告后声明，排除独占/排他许可期内、中止、欠年费、未经质权人同意的质押等五种情形（第85、86条）。
- 汇款缴费 → 缴费日是邮戳日/银行汇出日，不是专利局收到日（第111条）。

## 失权信号

- 申请费2个月或受理通知15日将届满未缴；授权通知后2个月登记期将届满。
- 优先权副本、保藏证明（4个月）、宽限期证明（2个月）只声明未补件。
- 年费进入6个月滞纳期；PCT 优先权日起30/32个月将届满未办进入。
- 无效请求提出后1个月补证期将过；归属纠纷中止满1年未请求延长。
- 在中国完成的发明未经保密审查就准备出境申请。

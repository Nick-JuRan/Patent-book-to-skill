# 中华人民共和国专利法实施细则（2023年修订）
**制定机关**：国务院（2001年国务院令第306号公布，2002、2010、2023年三次修订） | **结构**：13 章 149 条 | **生成日期**：2026-09-29

## 核心规则

**手续、日期、期限、恢复（ch01）**
- 手续须书面，合规电子形式视为书面；文件用中文，外文证件限期不补译文视为未提交（第2、3条）。递交日：邮寄看邮戳日、电子看进入系统日；送达日：邮寄自发文日满15日推定、电子以进入认可系统日、公告满1个月视为送达（第4条）。
- 期限起算日不计入，按相应日届满，逢休假日顺延（第5条）。误期两条恢复路径：不可抗拒事由——障碍消除起2个月且届满起2年内；正当理由——收到通知起2个月并缴费；指定期限可在届满前请求延长；宽限期、优先权期限、专利权期限、诉讼时效不可恢复（第6条）。
- 在中国完成的发明或实用新型向外国申请先保密审查，向专利局提交国际申请视为同时请求；国防利益的走国防专利（第7–9条）。职务发明三类情形含离职1年内；发明人须有创造性贡献；转让、许可（备案3个月）、质押（共同登记）（第12–15条）。

**申请文件与优先权（ch02）**
- 请求书九项、说明书五段带标题、独立权利要求写前序 + 特征部分、从属在后、多项从属只能择一引用；名称、术语、附图标记三对一致；禁用引用语、宣传语（第17–26条）。
- 生物材料：保藏不晚于申请日/优先权日，证明与存活证明4个月内交，逾期视为未提交保藏（第27条）；遗传资源须说明直接和原始来源（第29条）。
- 宽限期（法24(2)(3)）：申请时声明 + 2个月证明，缺一不适用（第33条）；优先权声明三要素可限期补正，逾期视为未要求；本国优先权使在先申请视为撤回；恢复2个月，增改16个月/4个月（第34–37条）。单一性 = 相同或相应的特定技术特征（第39条）；相似外观设计 ≤10项，成套产品同一大类（第40条）。

**受理、初审、实审、授权（ch03）**
- 受理只看最低文件集（实用新型须含附图）；六种不予受理情形；已要求优先权的缺件可援引在先申请2个月内补交并保留申请日，补交附图则申请日改为补交日（第43–46条）。同日双报须声明，授权前放弃实用新型（第47条）。分案最迟在登记手续期限届满前，驳回/撤回后不得分案，不改类别、不超范围（第48、49条）。
- 初审按发明/实用新型/外观设计三份清单查明显缺陷，不答复视为撤回（第50条）；主动修改：发明在提实审时及进入实审通知起3个月内，实用新型/外观设计申请日起2个月内（第57条）；实审驳回理由是第59条的封闭清单；授权通知起2个月办登记，否则视为放弃（第60条）；评价报告2个月内出具、一专利一份（第62、63条）。

**复审与无效（ch04）**
- 复审请求书格式不合视为未提出，主体或期限不符不予受理；修改仅限消除驳回缺陷；不答复复审通知视为撤回；结果只有维持驳回或撤销驳回继续审查（第65–68条）。
- 无效请求书理由与证据逐项对应、一式两份，理由限于法定清单（第69条）；四类不予受理含一事不再理（第70条）；请求日起1个月内补充理由证据，逾期可不予考虑（第71条）；专利权人只能缩小权利要求（第73条）；请求人缺席口审视为撤回，专利权人缺席则缺席审理（第74条）；指定期限不得延长（第75条）。

**期限补偿、许可、奖酬（ch05–ch07）**
- 授权延迟补偿：申请日满4年且实审请求日满3年后授权，公告起3个月内请求，天数 = 起算日至授权公告日 − 合理延迟 − 申请人引起的延迟；双报换取的发明不补偿（第77–79条）。新药补偿：上市许可起3个月内请求，一药一专利、一专利一药，天数 = 申请日至上市许可日 − 5年，受法42.3 的5年/14年上限（第80–84条）。
- 开放许可声明在授权公告后提出，五种禁止情形（独占/排他许可期内、中止、欠年费、未经质权人同意的质押等），达成后备案，禁止虚假声明（第85–88条）；强制许可："未充分实施"以国内需求为标尺，程序为请求书 → 限期答辩 → 决定预告，使用费裁决3个月（第89–91条）。
- 职务发明奖酬：约定或规章优先；兜底奖金授权公告起3个月内，发明≥4000元、实用新型/外观设计≥1500元；报酬依促进科技成果转化法（第92–94条）。

**保护、登记公报、费用（ch08–ch10）**
- 处理与调解主体为省级及有条件的地级部门；重大影响案件四种情形；多头请求以最先受理为准；无效请求被受理后可请求中止处理（第95–98条）。不诚信申请或开放许可造假：警告 + 10万元以下罚款（第100条）；假冒专利五种情形，善意销售者仅责令停止（第101条）；归属纠纷或法院保全可中止程序，1年内须请求延长（第103–105条）。
- 登记簿十二类事项是权利状态底账，公报十八项对外公示，公报与单行本免费查阅（第106–108条）。
- 费用十三项；缴费日按缴纳日/邮戳日/银行汇出日；申请费等自申请日起2个月（或受理通知起15日）否则视为撤回；请求费逾期视为未提出；授权当年年费随登记手续缴；年费滞纳期6个月、每超1个月加收5%，期满未缴自应缴日终止；多缴错缴3年内可退，缴费困难可减缴（第110–117条）。

**国际申请（ch11、ch12）**
- PCT：国际申请日即中国申请日；优先权日起30个月进入，32个月为付费宽限；中文声明 + 缴费 + 说明书权利要求书译文齐备才有进入日；32个月未进入 → 效力终止且不能依第6条恢复；进入日起2个月补修改译文、宽限期证明、优先权费、恢复优先权，4个月补保藏事项；译文错误改正限公布准备前或进入实审通知起3个月；授权后译文错误"大则缩至原文、小则维持"；未检索部分缴单一性恢复费（第118–135条）。
- 海牙：指定中国的国际注册申请视为国内外观设计申请，国际注册日 = 申请日；国际局公布后审查并通报结果；优先权副本3个月、宽限期证明2个月、分案2个月均自公布起算；给予保护决定公告后专利权生效（第136–144条）。

**附则（ch13）**：已公布/公告的案卷与登记簿经同意可查阅；失效申请案卷存2年、失效专利权案卷存3年；签章与代理机构盖章、著录事项变更、只能挂号信函、一函一案；审查指南依法与本细则制定（第145–149条）。
